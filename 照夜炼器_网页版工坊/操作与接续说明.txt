照夜炼器 · 沉浸工坊 v0.4

开始试玩
双击唯一可玩入口 index.html。运行不需要 Unity、Node、服务器或网络。需支持 WebGL 的浏览器，已实测本机 Edge。进度只在本次页面内存中，刷新会重置；成品可导出 JSON，本版没有导入恢复功能。

本版范围
参考东方写实题材的墨色、旧铜金、朱砂印记和克制 HUD，重做材料页、工具条、炉录、温态与操作反馈。场景加入旧石地、铜灯、窗格、原创纹饰，保留真实 WebGL 网格、阴影和金属材质。本版仍为程序模型原型，不等于《黑神话：悟空》的精模、扫描资产或商业级美术品质；未使用原作图片、模型、字体或图标。

工艺流程
择材 → 加热锻形 → 浸淬 → 回火 → 磨刃 → 描纹 → 验器。
当前原材是灵材预制器胚，不模拟矿石冶炼；不含经营、委托、弟子、战斗或 Steam 接入。
每步须先开始；阅读时温态冻结。暂停、切换窗口和打开炉录会冻结工艺，取消未完成手势，回来后需手动继续。
风门约 60% 可慢慢热透青纹铁；移至砧台，再选点锤或提锤。提锤按住真实剑胚部位，向上提、向下回落、松手落锤，也可直接向下划至少 24px；行程决定力度，一次手势最多一击。回炉不会补回已经锤薄的部分。
淬火先回热，再用夹钳拖入水池，松手放稳。深度决定真实覆盖，不需不停摇动。
回火风门约 40%，翻面均衡受热。磨刃沿两条刃带滑磨，同一个小点不能刷满；刻纹沿线连续描行，可从光点续描，不能点终点跳段。
可带着当前工艺继续，但未加工处与缺陷不会自动补满。

PC 操作
1 / 2 / 3：选择当前工序第 1 / 2 / 3 个工具（锻形为夹钳 / 点锤 / 提锤）。
F：翻面。R：回炉。E：移至砧台。
按住 Q：临时旋转视角；松开 Q 明确返回工具操作，即使此前开启了持续旋转。
“旋转视角”按钮：持续旋转开关。滚轮：缩放。
V：器图开关，不改变评分和接触判定。
H：净观 / 还原 HUD；净观的返回按钮或 Esc 也可恢复。
P：暂停 / 继续。Enter：确认、开始或推进，不使用空格卡时机。
Tab：仅在画布或页面背景焦点时打开炉录；按钮、输入框与弹窗内保留正常焦点遍历。L 也可打开炉录。
Esc：取消当前未提交手势或退出净观。滑杆输入时不会截获数字快捷键。
手机保留可点按工具、视角按钮及拖拽加工；窄幅净观自动调整取景。

跨设备开发
Source：界面、核心工艺、3D 应用与内嵌 Three.js 源码；BuildTools：拼装与文件校验；tests：完整工艺与新版 UI 测试。
先安装 Node.js 22+，在本文件所在目录运行 npm ci --ignore-scripts --no-audit --no-fund。
npm run build：生成 build/index.html；为保护旧文件，存在则拒绝覆盖。也可 node BuildTools/build.cjs --output build/index-next.html。
npm run check：核对交付文件、可玩副本、报告与源码哈希，不等于新执行游戏测试。
npm test：执行完整 217 项回归。npm run test:ui：执行新版 UI 检查。
Windows 默认探测已安装 Edge；其他路径用 FORGE_BROWSER_PATH。完整回归可用 FORGE_HTML_PATH 指定新构建入口，FORGE_TEST_OUTPUT 指定新证据目录；UI 测试默认检查根 index.html，新证据默认写入忽略的 test-results；FORGE_UI_OUTPUT 可指定新输出目录。PLAYWRIGHT_MODULE_PATH 仅在复用已有模块时设置。
修改游戏后必须重新构建并重新测试，更新唯一入口、报告和交付清单，不能用本版报告冒充新源码验收。
最终开发包不含 node_modules、浏览器用户目录、缓存、参考图或原始私有日志。
仓库使用固定目录“照夜炼器_网页版工坊”，今后在本目录迭代。当前树仅保留最新网页，v0.1、v0.2、v0.3 可在 Git 历史提交中查看；不重复上传整包 ZIP 或备用 HTML。Unity 工程是独立路线，不作网页重复版本处理。
