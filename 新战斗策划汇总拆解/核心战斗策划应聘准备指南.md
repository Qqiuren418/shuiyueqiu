# 核心战斗策划（角色向）应聘准备指南

> 适用对象：应聘 UE5 3D ARPG 项目"核心战斗策划（角色向）"岗位的候选人。本文从 JD 反推招聘方真实筛选逻辑，给出简历、作品集、面试的系统性准备路线。

---

## 一、先看清这份JD在筛什么样的人

这份JD的关键词不是"3年经验"这种硬门槛，而是藏在中段的几个**能力锚点**——招聘方真正用来区分候选人的东西：

- **手感打磨的方法论**：能不能讲清楚"为什么这一帧要加2f命中停顿""取消窗口开在哪、为什么""预输入缓冲设几帧、对操作感的影响"。
- **角色战斗设计的系统性认知**：能不能从操作身份 → 连段逻辑 → 技能循环 → 资源管理这条链路讲清楚一个角色是怎么"立起来"的。
- **技术协作能力**：UE5 / GAS / AnimBP 不是要你会写代码，而是要你能和程序"同语言对话"，看懂逻辑、提对需求。
- **拆解产出**：对标产品的深度拆解文档是"硬通货"，比简历上写"深度游玩动作游戏"有说服力100倍。

**核心策略**：把"我做过什么"转化为"我做出过什么具体决策、为什么这么决策、结果如何"，并用品类拆解和Demo作品把抽象能力变成可验证的实物。

## 二、简历制作的要点

### 1. 结构（按权重排序，不要按时间倒序铺）

1. **个人简介**（3-4行）：定位自己是"角色向战斗策划"，一句话说清主力项目品类和主导过的角色数量。例如："4年ARPG战斗策划，主导过《XX》3个主力角色的战斗设计与手感打磨，累计上线12个角色。"
2. **核心项目经历**（重点）：每个项目下用"角色 × 职责 × 决策 × 结果"四段式，而不是"负责战斗系统设计"这种无信息量描述。
3. **能力专长**：手感打磨 / 技能系统设计 / 数值平衡 / UE5协作 —— 每项配一句具体方法论。
4. **作品集链接**：拆解文档、Demo视频、参数表（独立链接或PDF附件）。
5. **游戏经历**：列深度游玩的对标产品，标注"已拆解"的。

### 2. 项目经历的四段式示例

> **角色**：主导《XX》主角A的战斗设计与手感打磨
> **决策**：建立取消链规则（普攻3连任意帧可取消进闪避，前100ms为高优窗口）；命中停顿分级（轻击2f / 重击4f / Boss受击6f）；预输入缓冲设为4f。
> **协作**：与动画师定义5段攻击的关键帧节奏与判定时序；与程序搭建GAS技能框架的配置工具链。
> **结果**：角色上线后玩家操作满意度调研4.6/5；该角色成为后续3个角色的手感基准模板。

每一句话都带**具体数字、具体术语、具体决策理由**。这是筛选简历的策划负责人最想看到的东西——它证明你不只是"参与过"，而是"决策过"。

### 3. 要避免的几个坑

- 别写"热爱游戏""玩过上千款游戏"——这是噪声，用一个拆解文档代替一千句话。
- 别把动作游戏经历和MMO/RPG经历混在一起写——岗位是ARPG角色向，弱相关经历压缩到一行。
- 别罗列工具名（Word/Excel/Visio）——这是学生简历的做法。
- 别用同一份简历投所有公司——这份JD强调"角色向"和"手感"，投隔壁技术向岗位就要换一版强调代码实现。

## 三、作品集——真正的差异化武器

作品集是这份JD应聘的胜负手。JD的加分项里写了"公开拆解文档 / Demo / 原型"——这其实是招聘方在告诉你"我们看重这个"。建议准备三类：

### 1. 竞品拆解文档（必做，至少2份）

选对标产品（《原神》《绝区零》《怪物猎人》《战神》《艾尔登法环》《鬼泣》《只狼》）做深度拆解，每份10-30页，覆盖：

- **角色操作身份分析**：这个角色的核心机制是什么（资源管理？取消链？派生系统？），操作身份一句话定义。
- **连段与取消规则拆解**：用帧图 / 时序图列出普攻连段的每一帧、判定窗口、取消点、可取消进哪些动作。
- **手感参数反推**：通过逐帧录制视频反推命中停顿帧数、预输入缓冲帧数、硬直层级。这是最有技术含量的部分。
- **技能循环与数值**：技能CD / 资源消耗 / DPS曲线，分析强度梯度。
- **设计意图推论**：为什么这么设计，解决了什么体验问题，有什么可借鉴 / 可改进。

格式用PDF（带帧图、时序图、对比表格），别用PPT——PDF更适合深度阅读。

### 2. 个人Demo / 原型（强加分，能做就做）

用UE5搭一个最小可玩的角色战斗原型（一个测试关卡 + 一套技能 + 一个木桩Boss），重点展示手感调优能力。不需要美术资源，白盒 + 基础动画即可，关键是**手感参数可调、可对比**。

如果能做一个简单的参数面板（命中停顿 / 取消窗口 / 预输入缓冲可实时调整），直接秒杀90%的候选人。录一段3-5分钟的视频，**对比"调优前"和"调优后"的手感差异**，旁白讲你改了哪些参数、为什么。这是最强的说服材料。

### 3. 参数表 / 设计文档样本

脱敏后附一份你做过的角色技能设计书或手感参数表（敏感数值改掉）。证明你有规范的文档输出能力，这是JD里"输出可执行设计文档"的直接印证。

## 四、面试准备要点

这份JD的面试几乎一定会考以下几类问题，提前准备好答案。

### 1. 手感类（高频，必考）

- "你觉得好手感的本质是什么？拆解一下。"
- "给你一段动作视频，告诉我手感问题在哪、怎么改。"
- "命中停顿、取消窗口、预输入缓冲，分别解决什么体验问题？能不能不要？"
- "你怎么建立手感标准？怎么让团队按这个标准执行？"

### 2. 设计类

- "设计一个新角色，从0讲一遍你的设计流程。"
- "怎么让两个角色手感差异化，不只是技能不一样？"
- "Boss战从角色侧反推，你会提哪些设计要求？"

### 3. 技术类

- "GAS的Ability结构你了解吗？技能逻辑怎么组织？"
- "AnimBP的状态机 / 混合空间你用过吗？怎么和动画师协作？"
- "你看过UE的哪部分战斗相关代码？"

### 4. 品类素养类

- "《绝区零》和《原神》的战斗手感差异在哪？为什么？"
- "《怪物猎人》的取消链规则你怎么看？"
- "你觉得《艾尔登法环》的战斗手感好还是不好？为什么？"（考你是不是真懂，别答"很好"就完了）

### 5. 准备方法

把每个对标产品的核心战斗机制用自己的话讲一遍，录下来自己听，直到能脱口而出且逻辑清晰。准备1-2个"白板题"演练——现场设计一个角色或调一段动作。

## 五、着重体现的经历和能力（按JD权重排序）

1. **角色战斗设计的主导经历** —— 岗位核心，必须放在简历最显眼位置。讲清楚主导过几个角色、什么品类、上线后的表现。
2. **手感打磨的实战方法论** —— 用具体决策案例证明你"调过、调出过结果"。这是JD第2条职责，也是这份岗位区别于普通战斗策划的关键。
3. **UE5 / GAS协作能力** —— 技术能力是合作门槛，能讲清楚怎么和程序 / 动画协作搭建技能框架。
4. **系统性拆解能力** —— 用拆解文档证明你的品类素养不是"玩得多"而是"想得深"。
5. **数值平衡能力** —— 角色向通常要兼顾，提一句你搭过伤害公式 / 调过强度梯度即可，不必深入。
6. **跨职能推动能力** —— 一个案例讲清楚你怎么推动动画 / 特效 / 程序 / 音频多职能协作落地一个角色。

---

## 六、最后一条建议

如果你现在还没做过UE5项目，但目标是这种岗位，优先级最高的补强动作是——**用UE5做一个角色战斗原型Demo**。一个能跑、能调手感、能讲清楚为什么这么调的Demo，比再写一份拆解文档更能证明"角色向 + 手感"这条赛道的能力。

行动清单：

- [ ] 选定2个对标产品，开始逐帧拆解文档
- [ ] 整理主导角色的设计决策案例（脱敏）
- [ ] 用UE5搭最小可玩战斗原型 + 参数可调面板
- [ ] 录制"调优前后对比"视频并旁白讲解
- [ ] 重写简历为四段式结构，避免四个常见坑
- [ ] 针对四类面试问题逐题准备口头答案
