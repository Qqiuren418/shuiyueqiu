### 1.1 基本信息

- **游戏名称**：黑神话：悟空

### 1.2 战斗定位一句话

**以棍势为核心资源、识破为核心防御机制、法术与变身为爆发窗口的单人写实动作战斗。**

### 1.3 目标用户画像

- **核心受众**：动作游戏玩家 + 国产 3A 关注者 + 西游 IP 粉丝的交集

  - **下限兜底**：法术（定身/聚形散气）+ 变身无敌帧 + 救命毫毛，给手残玩家提供"用资源换通关"的路径
  - **上限表达**：识破 + 切手技 + 棍势满蓄连段，给硬核玩家提供"无伤裸棍过 Boss"的空间

## 2. 角色操作身份分析

### 2.1 角色选择

拆解主角"天命人"——单一可控角色，通过三种棍法架势切换 + 法术/变身配置实现 Build 差异化。这是本作区别于多角色动作游戏（如鬼泣角色切换、原神角色切换）的核心特征：**用"架势+Build"而非"角色切换"实现战斗差异**。

### 2.2 核心机制提炼

天命人的战斗循环同时具备三类特征，但主导身份是**资源管理型**：

- **资源管理型（主导）**：棍势（焦点）是核心战斗资源，轻棍积攒→重棍释放。所有攻防决策围绕"何时攒、何时花"。
- **精准判定型（进阶）**：识破（完美闪避）与切手技是高上限表达，将防御转化为资源获取。
- **状态切换型（Build 维度）**：三种棍法架势（劈/立/戳）+ 变身形态提供不同的技能组与战斗风格。

**一句话操作身份定义**：

> 棍势驱动的资源型战士——靠轻棍连段与识破积累焦点，用法术创造输出窗口，用重棍满蓄与变身爆发收割。

### 2.3 三棍法操作身份对比

| 维度 | 劈棍法 | 立棍法 | 戳棍法 |
|---|---|---|---|
| 核心机制 | 蓄力重棍 + 捣蒜打 | 空中连段 + 旋转 AoE | 突刺穿透 + 变化招式 |
| 攻击距离 | 中 | 中（含跳跃） | 远（含位移） |
| 群战能力 | 中 | 强（旋转 AoE） | 中（直线穿透） |
| 单体爆发 | 强（满蓄） | 中 | 中（依赖变化招式） |
| 进阶技巧 | 识破反击接重棍 | 跳起加成 | 突刺位移调整 |
| 操作身份 | 攻守均衡型 | 空中机动/群战型 | 远距穿透/拉扯型 |
| 适合 Boss | 通用，识破流首选 | 群战 + 空中优势 Boss | 直线型 + 风筝型 Boss |

## 3. 连段与取消规则拆解（核心章节）

### 3.1 录制与标注方法

- **录制工具**：OBS 60fps 固定帧率
- **逐帧分析**：DaVinci Resolve 帧步进
- **时间戳标注**：MM:SS:FF（FF 为帧号，60fps）
- **数据声明**：本节数据为基于录屏反推的近似值，非官方数据，误差 ±2f。后续用 UE5 逆向或 MOD 工具可进一步精确化。

### 3.2 劈棍法普攻连段帧图（以劈棍 5 连为例）

> 以下为 60fps 录屏反推，非精确解包数据，误差 ±2f。所有"取消窗口"指可被闪避/重棍取消的最早帧。

| 击数 | 起手前摇 (f) | 活跃判定窗口 (f) | 后摇 (f) | 取消窗口开放帧 | 可取消进 |
|---|---|---|---|---|---|
| 第 1 击 | ~10f | ~6f | ~18f | 第 12f 起 | 闪避 / 重棍 / 切手技 |
| 第 2 击 | ~8f | ~6f | ~20f | 第 14f 起 | 闪避 / 重棍 |
| 第 3 击 | ~12f | ~8f | ~24f（棍势 +1） | 第 16f 起 | 闪避 / 重棍（识破窗口） |
| 第 4 击 | ~10f | ~6f | ~22f | 第 14f 起 | 闪避 / 重棍 |
| 第 5 击 | ~14f | ~10f | ~30f（棍势 +1，共 2 点） | 第 18f 起 | 闪避（重棍需等后摇结束） |

**关键观察**：

1. **每击后摇均可被闪避取消**，这是动作 ARPG 的基础容错设计。
2. **第 3 击与第 5 击是棍势获取节点**，设计上鼓励玩家"打满连段"而非"贪刀"——但识破机制提供了"中途跳出"的高收益路径。
3. **第 5 击后摇最长（~30f）**，且重棍不可取消，强制玩家评估风险：贪满 5 连换取 2 点棍势 vs 提前跳出保命。
4. **取消优先级**：闪避 > 重棍 > 切手技。闪避是最高优先级的"硬取消"，重棍是"软取消"（消耗资源换输出）。

### 3.3 取消链规则

**取消优先级层级**（高→低）：

1. **闪避**（含识破）：最高优先级，几乎可从任何动作后摇中取消。识破窗口在受击前约 8-12f（推测，待精确验证）。
2. **重棍**：可从轻棍连段中取消（消耗棍势），构成"轻棍→重棍"的核心连段逻辑。
3. **切手技**（棍法专属招式）：可从特定轻棍击数后取消，是进阶连段的关键。
4. **法术**：可在任何动作后摇中释放，是"紧急打断"的逃生路径。
5. **变身**：可在任何时机释放，变身瞬间有无敌帧，是"硬逃"手段。

**预输入缓冲**：

- **缓冲窗口**：约 4-6f（推测），按下闪避后会在当前动作结束后自动触发。
- **跨动作缓冲**：存在，在普攻第 N 击后摇期按下闪避，会在可取消帧到达时自动触发。
- **缓冲优先级**：最后输入的动作优先（最后输入优先），但闪避与法术冲突时法术优先（推测，待验证）。

### 3.4 关键观察与设计推论

1. **取消规则解决了"连段流畅 vs 贪刀惩罚"的矛盾**：玩家可以打满 5 连拿满棍势，但代价是第 5 击的长后摇；也可以在第 3 击后跳出，少拿 1 点棍势换保命。这是典型的风险收益权衡。
2. **识破作为"第三条路"**：不走"贪满"也不走"提前跳出"，而是在第 3 击后摇期识破接重棍反击，既不丢棍势还能多拿识破棍势奖励。识破是这套战斗系统的**上限阀门**。
3. **法术作为"硬打断"**：法术可在任何后摇中释放，意味着玩家永远有"紧急出口"。这是手残兜底机制——但法术有 CD，不能滥用。

## 4. 手感参数反推（核心章节）

> 本章所有数值为基于 60fps 录屏反推的近似值，非官方数据，误差 ±2f。完整反推方法见每节小注。

### 4.1 命中停顿

| 攻击类型 | 命中停顿帧数（60fps） | 反推方法 | 误差 |
|---|---|---|---|
| 轻棍命中（普通怪） | ~3f | 命中瞬间逐帧计数画面与受击体静止帧 | ±1f |
| 轻棍命中（Boss） | ~4f | 同上，Boss 受击停顿略长 | ±1f |
| 重棍 1 焦点 | ~6f | 蓄力释放命中瞬间计数 | ±1f |
| 重棍 3 焦点 | ~10f | 满蓄命中瞬间计数 | ±2f |
| 重棍 4 焦点（金箍棒金光） | ~14f + 慢动作 | 满蓄 + 金箍棒特效触发 | ±2f |
| 识破反击命中 | ~6f + 镜头微推 | 识破成功后的反击命中 | ±1f |
| 变身大招命中 | ~12-18f（视变身类型） | 变身技能命中瞬间 | ±2f |

**设计推论**：

- 命中停顿按"攻击重量"分级，轻棍是"快打轻顿"，重棍满蓄是"重击强顿+慢动作"——这是**攻击重量感**的核心表达。
- Boss 受击停顿略长于普通怪，强化"打 Boss 的史诗感"。
- 识破反击的停顿比普攻重棍略长，作为"精准判定的奖励反馈"。

## 5. 技能循环与数值

### 5.1 技能组结构

| 技能模块 | 功能定位 | 资源消耗 |
|---|---|---|
| 轻棍连段（5 连） | 输出 + 棍势积攒 | 无（气力消耗低） |
| 重棍（蓄力） | 爆发输出 | 棍势（1-4 焦点） |
| 闪避 | 防御 + 位移 | 气力 |
| 识破（完美闪避） | 防御 + 反击 + 棍势获取 | 无（精准判定奖励） |
| 切手技（棍法专属） | 进阶连段 + 派生 | 棍势 / 气力 |
| 法术（4 槽位） | 控制 / 保命 / 增伤 | 法力 + CD |
| 变身 | 爆发 + 无敌 + 独立血条 | 法力 + CD |
| 精魄 | 补充输出 / 防御 / 辅助 | 气力 |

### 5.2 资源循环

**核心资源**：棍势（焦点）

**棍势获取**：

- 轻棍第 3 击：+1 焦点
- 轻棍第 5 击：+1 焦点（累计 2 点）
- 持续蓄力：长按重棍键积累（满蓄 4 焦点）
- 识破成功：+1 焦点（推测，待验证）

**棍势消耗**：

- 重棍释放：消耗当前所有焦点，焦点越多伤害倍率越高（1→1.5x →2.0x →3.0x+）

**循环节奏**：

```
轻棍连段（积攒） → 棍势达标 → 重棍满蓄（爆发） → 闪避/识破（保命） → 循环
                ↑                                       ↓
                └───── 法术窗口（定身/聚形散气）←──────┘
```

**法力资源**：法术共享法力池，法力通过战斗自然恢复（缓慢）+ 道具恢复。法术 CD 独立计时，限制了爆发频率。

### 5.3 数值框架

**伤害公式推测**：

```
最终伤害 = 基础攻击 × 技能倍率 × (1 + 暴击伤害) × 属性克制系数 × 减伤系数
```

**重棍倍率分布**（推测）：

- 1 焦点：~1.0x
- 2 焦点：~1.5x
- 3 焦点：~2.0x
- 4 焦点：~3.0x + 金箍棒专属加成

**装备影响**：

- 武器：倍率加成（如出云棍蓄力加成）+ 属性附加
- 防具：套装效果（减伤/属性抗性/资源恢复）
- 精魄：技能加成
- 根器/变身：独立技能模组与数值

### 5.4 强度梯度

- 本作无 PVP，强度梯度主要体现在"通关效率"与"高难度 Boss（二周目/连战模式）"的表现
- T0 Build：识破流 + 满蓄重棍 + 定身法（上限最高，操作要求高）
- T1 Build：聚形散气破隐暴击流 + 高伤精魄（稳定，操作要求中）
- T2 Build：变身依赖流 + 法术窗口（下限兜底，操作要求低）

## 6. Boss 战与战斗博弈

### 6.1 Boss 行为模式

- **攻击链结构**：Boss 多采用 2-4 击连段套路，含变招（A→B 或 A→C，按距离/状态切换）
- **阶段切换**：多数 Boss 有 2 阶段（血量 50% 触发），部分有 3 阶段。阶段切换伴随新技能解锁与攻击频率提升
- **受击反馈**：Boss 有部位受击判定（头/腿/尾等），特定部位累积受击后破防，破防窗口可满蓄重棍

### 6.2 角色 vs Boss 的博弈结构

**核心博弈节点**：

1. **识破博弈**：Boss 攻击前摇期识破→重棍反击，是高收益路径。但识破窗口严苛（~8-12f），失败则吃满伤害
2. **定身窗口**：Boss 大招前摇或硬直期定身→满蓄重棍，是稳定输出路径
3. **变身博弈**：Boss 二阶段强攻期变身→用独立血条吃伤害+输出，是"用资源换空间"
4. **破防博弈**：累积部位伤害破防→满蓄重棍收割

**攻防转换节奏**：

- Boss 攻击期：玩家以闪避/识破为主，寻找反击窗口
- Boss 硬直期：玩家以轻棍连段 + 重棍爆发为主
- Boss 阶段切换：玩家用法术/变身覆盖切换动画，争取免费输出

### 6.3 难度曲线

- **普通**：法术 + 变身依赖型玩家可过，识破非必需
- **困难**（二周目）：数值压力提升，要求更精准的识破与资源管理
- **连战模式**：限制法术/变身使用，强制玩家走识破 + 重棍流派

## 7. 设计意图推论与可借鉴点

### 7.1 设计意图推论

**为什么取消窗口开在第 12-18f？**

- 容错（~5f 缓冲）让普通玩家能稳定连段，但第 5 击长后摇（~30f）强制玩家做风险决策
- 反事实：如果第 5 击后摇也短，连段会无脑贪满，丧失风险收益权衡

**为什么识破给棍势奖励？**

- 识破是高难度操作，给棍势奖励将"防御成功"转化为"资源获取"，形成攻防一体的循环
- 反事实：如果识破不给棍势，识破就只是"高级闪避"，玩家会倾向于普通闪避+法术，丧失上限表达

**为什么法术可在任何后摇中释放？**

- 法术是"硬打断"，给手残玩家提供紧急出口。但有 CD 限制，不能滥用
- 反事实：如果法术也受取消窗口限制，手残玩家会卡在连段中无法逃生，下限崩塌

**为什么用"架势切换"而非"角色切换"？**

- 单角色叙事一致性（天命人只有一个）
- 架势切换成本低（无需重新练角色），降低 Build 构建门槛
- 反事实：如果用多角色切换，叙事会割裂，且每个角色都要做完整技能组，开发成本爆炸

### 7.2 可借鉴点

1. **棍势资源循环**：轻棍积攒→重棍爆发的"攒条-释放"模型，简单清晰但深度足够。可迁移到任何 ARPG 的角色资源设计
2. **识破作为攻防枢纽**：将防御动作（闪避）与资源获取（棍势）绑定，把防御从"被动保命"升级为"主动积累"。这是手感差异化的关键设计
3. **法术作为硬打断兜底**：给手残玩家提供"用资源换生存"的路径，但用 CD 限制滥用。下限兜底不破坏上限
4. **变身独立血条**：用"额外血条"而非"减伤"实现爆发窗口，既给输出空间又控制了无敌时间长度
5. **三棍法差异化**：用架势切换实现 Build 差异，而非角色切换。适合单角色叙事的 ARPG

### 7.3 可改进点

1. **棍法切换流畅度**：架势切换有动画硬直，无法在连段中无缝切换。如果支持连段中切架势派生，上限会更高
2. **识破反馈可视性**：识破成功的视觉反馈不够明显（相比只狼的弹刀火花），新手难以判断是否触发
3. **法术 Build 单一化**：定身法过于万金油，导致法术 Build 趋同。可加强其他法术的特定场景优势
4. **空中战斗深度不足**：立棍法的空中连段较浅，相比鬼泣的空中连段系统差距明显

**对比结论**：

- 黑神话的战斗哲学是"用资源管理降低下限，用识破提升上限"，介于只狼的硬核与战神的休闲之间
- 识破窗口比只狼弹刀更宽容（~8-12f vs ~6-10f），但惩罚也更重（只狼弹刀失败只掉架势条，黑神话识破失败直接吃伤害）
- 棍势系统比怪猎蓄力更灵活（可积攒可释放），但比战神怒气更深度（怒气只管大招，棍势管所有重棍）

## 9. 结论与一页纸总结

**核心发现**：

1. **棍势是整套战斗的引擎**：轻棍→棍势→重棍的循环驱动所有战斗决策，简单但深度足够。识破将防御接入循环，实现攻防一体
2. **手感的关键参数决策**：取消窗口开在 12-18f（容错+缓冲 5f）+ 命中停顿按重量分级（3-14f）+ 第 5 击长后摇强制风险决策
3. **下限兜底不破坏上限**：法术硬打断 + 变身独立血条给手残玩家出口，但有 CD/法力限制；识破 + 满蓄给硬核玩家上限，但操作要求高

**对我们项目的 3 条可借鉴启示**：

1. **资源循环要做攻防一体**：让防御动作（闪避/格挡）也能获取资源，而非纯粹消耗。这是手感的差异化关键
2. **取消窗口 + 长后摇做风险决策**：不要让所有动作的取消窗口一样宽，关键动作（如第 5 击）用长后摇强制玩家权衡
3. **下限兜底用"资源"而非"自动"**：用法术/变身这类玩家主动释放的资源做兜底，而不是自动闪避/自动格挡。保留下限玩家的参与感
