## 1. 产品概述

### 1.1 基本信息

- **游戏名称**：只狼：影逝二度（Sekiro: Shadows Die Twice）
- **开发商**：FromSoftware
- **发行时间**：2019 年 3 月 22 日
- **平台**：PC（Steam） / PS4 / Xbox One
- **品类定位**：3D 动作冒险（魂系衍生，但以"打铁"弹刀为核心而非常规魂系翻滚躲避）
- **商业模式**：买断制

### 1.2 战斗定位一句话

**以弹刀（完美格挡）为攻防枢纽、以躯干值为生死线、以危字攻击的差异化应对为进阶深度的"打铁"动作战斗。**

### 1.3 目标用户画像

- **核心受众**：魂系玩家 + 动作游戏硬核玩家 + 和风忍者题材爱好者
- **操作上下限拉扯策略**：
  - **下限兜底极少**：本作几乎没有"用资源换通关"的逃课路径。忍义手道具（爆竹/雾鸦/伞）能辅助，但核心弹刀不可绕过。这是只狼区别于黑神话/绝区零的"硬核定位"——下限玩家必须"学会弹刀"才能通关
  - **上限表达极深**：无伤弹刀通关 / 不使用忍义手 / 不使用回血道具，给硬核玩家"纯粹打铁"的极致空间
  - **关键设计**：宫崎英高选择"做减法"——砍掉魂系的build多样性、装甲负重、魔法流派，只保留"一刀一弹"的纯粹攻防。这是只狼区别于黑魂/艾尔登法环的核心特征

## 2. 角色操作身份分析

### 2.1 角色选择

拆解主角"狼"——单一可控角色，固定武器（楔丸），通过忍义手道具与剑技流派实现有限 Build 差异。这是只狼区别于黑神话架势切换/绝区零角色切换的"极简身份"设计：**用一个角色、一把刀、一套动作模组，把战斗深度做到极致**。

### 2.2 核心机制提炼

狼的战斗循环主导身份是**精准判定型**：

- **精准判定型（主导）**：弹刀（完美格挡）是攻防枢纽。所有战斗决策围绕"何时攻、何时弹、何时识破"的精准时机判断。这是只狼的"打铁"灵魂。
- **资源管理型（并行）**：躯干值（Posture）是攻防双方的生死线。攻击与弹刀都累积敌方躯干值，满条触发"忍杀"处决；同时玩家自身也有躯干值，被弹反或受击会累积。
- **派生系统型（辅助）**：忍义手（爆竹/雾鸦/伞/火/机关伞等）提供有限的辅助工具，但核心战斗不依赖忍义手。

**一句话操作身份定义**：

> 弹刀驱动的精准判定型忍者——靠完美格挡和识破的精准时机做攻防枢纽，靠躯干值消耗做击杀路径，忍义手与剑技做辅助深度。

### 2.3 与魂系的操作身份对比

| 维度 | 只狼（狼） | 黑魂/艾尔登法环（主角） |
|---|---|---|
| 核心防御 | 弹刀（完美格挡） | 翻滚躲避 / 盾反 |
| 核心资源 | 躯干值（双方） | 生命值 + 法力/专注 |
| 武器多样性 | 固定一把（楔丸） | 多武器切换 |
| Build 多样性 | 极简（忍义手+剑技） | 极丰富（武器/魔法/护符/装甲） |
| 战斗节奏 | 高频攻防转换（打铁） | 慢节奏回合制（攻击-躲避） |
| 操作上限 | 极高（无伤弹刀） | 中高（翻滚时机） |
| 操作下限 | 低（无逃课空间） | 中（build兜底） |

## 3. 连段与取消规则拆解（核心章节）

### 3.1 录制与标注方法

- **录制工具**：OBS 60fps 固定帧率
- **逐帧分析**：DaVinci Resolve 帧步进
- **时间戳标注**：MM:SS:FF
- **数据声明**：本节数据为基于录屏反推的近似值，非官方数据，误差 ±2f。只狼的帧数据社区研究相对成熟，部分数据可参考社区拆解交叉验证。

### 3.2 普攻连段帧图（以楔丸普攻 4 连为例）

> 以下为 60fps 录屏反推，非精确解包数据，误差 ±2f。只狼的普攻连段深度有限，真正深度在弹刀与识破的精准判定。

| 击数 | 起手前摇 (f) | 活跃判定 (f) | 后摇 (f) | 取消窗口开放 | 可取消进 |
|---|---|---|---|---|---|
| 第 1 击 | ~8f | ~6f | ~14f | 第 10f 起 | 弹刀 / 识破 / 垫步 / 跳跃 |
| 第 2 击 | ~8f | ~6f | ~16f | 第 10f 起 | 弹刀 / 识破 / 垫步 / 跳跃 |
| 第 3 击 | ~10f | ~8f | ~18f | 第 12f 起 | 弹刀 / 识破 / 垫步 |
| 第 4 击 | ~12f | ~8f | ~24f | 第 14f 起 | 弹刀 / 垫步（识破需等后摇） |

**关键观察**：

1. **普攻连段深度有限**：只狼的普攻只有 4 连，且每击后摇均可被弹刀/垫步取消。深度不在"角色内连段"，而在"攻防转换的精准时机"。
2. **弹刀是最高优先级取消**：任何时候按格挡键，当前攻击动作立即被取消进入格挡状态。这是"打铁"流畅的根基——攻击与防御之间无缝切换。
3. **取消优先级**：弹刀 > 垫步 > 跳跃 > 识破。弹刀是"硬取消"，垫步是"软取消"（含无敌帧）。
4. **第 4 击后摇最长（~24f）**：但可被弹刀取消，因此实战中不会吃满后摇。

### 3.3 取消链规则

**取消优先级层级**（高→低）：

1. **弹刀（格挡）**：最高优先级，可从任何动作后摇中取消。完美格挡（受击前 ~6-10f 内输入）触发弹刀特效 + 大量躯干伤害 + 反击窗口。
2. **垫步**：含无敌帧，可从普攻/弹刀后摇中取消。识破是垫步的特殊变体（迎着突刺垫步触发）。
3. **跳跃**：可躲避横扫类危字攻击，可从普攻后摇中取消。
4. **识破**：针对突刺类危字攻击，迎着突刺方向垫步触发。识破成功造成 90 点躯干伤害（受攻击力/buff 加成）。
5. **忍义手**：可在普攻后摇中释放，提供辅助（爆竹硬直/雾鸦无敌/伞格挡）。
6. **剑技**：消耗纸人，可在特定时机取消派生（如一字斩/十字斩/水月）。

**弹刀的核心规则**：

- 完美格挡窗口：受击前约 6-10f 内输入格挡（推测，待精确验证）
- 完美格挡成功：触发火花特效 + 镜头微震 + 大量敌方躯干伤害 + 少量己方躯干值消耗
- 普通格挡（早弹/晚弹）：触发格挡但非完美，敌方躯干伤害少 + 己方躯干值消耗大
- 连续弹刀：可连续完美格挡多段攻击，每弹都给敌方累积躯干值

**预输入缓冲**：

- **缓冲窗口**：约 4-6f（推测），比绝区零窄，匹配硬核定位
- **跨动作缓冲**：存在但较短，普攻后摇期按下格挡，会在可取消帧到达时自动触发
- **连续弹刀缓冲**：连续按下格挡时，每弹之间有最短间隔（约 10-15f，推测），防止无脑连按

### 3.4 关键观察与设计推论

1. **弹刀取消解决了"攻防一体"的矛盾**：攻击与防御之间无缝切换，玩家可以"打一刀→弹一刀→打一刀"形成打铁节奏。这是只狼"高频攻防转换"的根基。
2. **连续弹刀的最短间隔防止了"无脑连按"**：如果连续弹刀无间隔限制，玩家可以无脑连按格挡触发完美弹反。最短间隔强制玩家"读节奏"而非"连按"。
3. **危字攻击的差异化应对是进阶深度**：突刺→识破 / 横扫→跳跃 / 回旋→垫步或跳跃。三类危字强制玩家"读懂敌人招式"而非"统一应对"。
4. **取消规则让"读招"成为核心乐趣**：弹刀窗口严苛（~6-10f），玩家必须读懂敌人攻击节奏才能连续弹刀。这是只狼"打铁"乐趣的来源——不是反应游戏，是节奏游戏。

- 忍杀的 30-60f 演出是"战斗胜利的高光时刻"，把节奏峰值交给演出
- Boss 弹刀成功也有停顿+火花，强化"敌人也会弹你的刀"的对称感

## 5. 技能循环与数值

### 5.1 技能组结构

| 技能模块 | 功能定位 | 资源消耗 |
|---|---|---|
| 普通攻击（连段） | 输出 + 累积敌方躯干值 | 无 |
| 完美格挡（弹刀） | 防御 + 大量累积敌方躯干值 | 己方躯干值（少量） |
| 普通格挡 | 防御 + 少量累积敌方躯干值 | 己方躯干值（大量） |
| 垫步 | 位移 + 无敌帧穿越 | 无 |
| 识破 | 反击突刺危字 + 90 点躯干伤害 | 无 |
| 跳跃 | 躲避横扫危字 + 位移 | 无 |
| 忍义手（多种） | 辅助（硬直/无敌/格挡/火焰） | 纸人 |
| 剑技（流派） | 进阶派生（一字斩/十字斩/水月等） | 纸人 |
| 忍杀（处决） | 击杀（躯干满条触发） | 无 |

### 5.2 资源循环

**核心资源**：躯干值（Posture）——双方共有

**躯干值获取**：

- 完美格挡成功：大量累积敌方躯干值 + 少量己方消耗
- 普通格挡成功：少量累积敌方躯干值 + 大量己方消耗
- 攻击命中：少量累积敌方躯干值
- 识破成功：90 点躯干伤害（受加成）
- 忍义手辅助：爆竹硬直期间可多打几刀

**躯干值恢复**：

- 不受击时缓慢恢复
- 完美格挡不消耗己方躯干值，连续弹刀不阻碍恢复
- 普通格挡大量消耗，阻碍恢复

**循环节奏**：

```
攻击命中（累积敌方躯干）→ 敌人攻击 → 完美格挡（大量累积敌方躯干）
    ↓                                          ↓
    敌人后摇（多打几刀）              敌人连续攻击（连续弹刀）
    ↓                                          ↓
    └──────────敌方躯干值满条 ←──────────────┘
                       ↓
                  忍杀处决 → 战斗胜利
```

**关键设计**：躯干值是双向的——玩家也在被累积躯干值。如果玩家乱弹（普通格挡多），己方躯干值会先满，被忍杀。这强制玩家"精准弹刀"而非"无脑格挡"。

### 5.3 数值框架

**躯干值公式推测**：

- 敌方躯干值累积 = 攻击躯干伤害 × (1 - 敌方躯干抗性) + 完美格挡躯干伤害
- 完美格挡躯干伤害 ≈ 普通攻击的 3-5 倍（推测）
- 普通格挡躯干伤害 ≈ 完美格挡的 1/3

**生命值 vs 躯干值**：

- 只狼有两条击杀路径：生命值归零或躯干值满条
- 生命值击杀：缓慢但稳定，适合"安全输出流"
- 躯干值击杀：快速但风险高，适合"打铁弹刀流"
- 躯干值会随时间衰减，生命值不会——这鼓励"主动进攻"维持躯干压力

### 5.4 强度梯度

- 本作无 PVP，强度梯度体现在"通关效率"与"高难度 Boss（交符/钟鬼模式）"的表现
- T0 Build：纯弹刀流 + 识破 + 不用忍义手（上限最高，操作要求极极高）
- T1 Build：弹刀 + 忍义手辅助（爆竹硬直/雾鸦无敌）（稳定，操作要求高）
- T2 Build：生命值击杀流（安全但慢，避开弹刀）

## 6. Boss 战与战斗博弈

### 6.1 Boss 行为模式

- **攻击链结构**：Boss 多采用 2-5 击连段套路，含变招（A→B 或 A→C）
- **危字攻击**：每个 Boss 有 1-3 种危字攻击（突刺/横扫/回旋），需差异化应对
- **阶段切换**：多数 Boss 有 2 阶段（血量 50% 触发），部分有 3 阶段。阶段切换伴随新招式 + 攻击频率提升
- **弹刀交互**：Boss 会弹反玩家攻击，强制玩家"不要贪刀"——这是只狼 Boss 设计的核心

### 6.2 角色 vs Boss 的博弈结构

**核心博弈节点**：

1. **弹刀博弈**：连续完美格挡 Boss 攻击链，累积敌方躯干值。失败（普通格挡多）→ 己方躯干值满 → 被忍杀
2. **危字应对博弈**：突刺→识破 / 横扫→跳跃 / 回旋→垫步。错误应对吃满伤害
3. **进攻博弈**：玩家攻击时 Boss 会弹反，强制玩家"打 1-2 刀就撤"或"读 Boss 弹反时机"
4. **躯干值衰减博弈**：躯干值会随时间衰减，玩家必须"持续施压"维持躯干压力，不能"等机会"

**攻防转换节奏**：

- Boss 攻击期：玩家以连续弹刀为主，寻找危字应对窗口
- Boss 硬直期：玩家以 1-2 刀攻击为主，不可贪刀（会被弹反）
- Boss 阶段切换：玩家以存好纸人/调整状态为主
- Boss 躯干满条：玩家触发忍杀处决

### 6.3 难度曲线

- **一周目**：Boss 弹刀窗口宽 + 躯干值衰减慢，学习为主
- **二周目（交符）**：弹刀窗口窄 + 躯干值衰减快 + Boss 攻击频率提升
- **钟鬼模式**：Boss 攻击力大幅提升 + 躯干值衰减极快，要求近乎完美的弹刀

## 7. 设计意图推论与可借鉴点

### 7.1 设计意图推论

**为什么用弹刀而非翻滚做核心防御？**

- 弹刀是"主动防御"——玩家主动读招时机格挡，而非"被动躲避"
- 弹刀同时是"防御 + 攻击"——完美格挡累积敌方躯干值，把防御转化为进攻
- 反事实：如果用翻滚做核心，战斗会变成"等机会输出"的回合制，丧失"高频攻防转换"的打铁节奏

**为什么躯干值是双向的？**

- 如果只有敌方躯干值，玩家可以无脑格挡，丧失精准判定的深度
- 双向躯干值强制玩家"精准弹刀"而非"乱弹"——乱弹会让己方躯干值先满
- 反事实：如果躯干值单向，弹刀变成"无脑连按格挡"，丧失读节奏乐趣

**为什么危字攻击要分三类？**

- 如果只有一类危字，玩家可以"统一应对"，丧失读招深度
- 三类危字（突刺/横扫/回旋）强制玩家"读懂招式"而非"统一反应"
- 反事实：如果只有一类危字，战斗会变成"弹刀+识破"的两键循环，深度不足

**为什么砍掉 Build 多样性？**

- Build 多样性会分散玩家对"弹刀"的注意力
- 宫崎英高选择"做减法"——砍掉武器/魔法/护符/装甲，只保留"一刀一弹"
- 反事实：如果有 Build 多样性，玩家会找逃课 build 绕过弹刀学习，违背"打铁"核心体验

### 7.2 可借鉴点

1. **弹刀做攻防一体**：完美格挡同时是防御和进攻——累积敌方躯干值。这是"防御即攻击"的设计典范，可迁移到任何 ARPG 的格挡系统设计
2. **双向躯干值做精准弹刀驱动**：让防御资源双向流动，强制玩家精准操作而非无脑防御。这是"硬核精准判定"的设计模板
3. **危字差异化应对做读招深度**：三类危字强制玩家"读懂招式"而非"统一应对"，是"读招深度"的优秀设计
4. **做减法聚焦核心体验**：砍掉 Build 多样性，把所有注意力聚焦在"一刀一弹"上。这是"少即是多"的设计哲学典范
5. **躯干值衰减做进攻驱动**：躯干值随时间衰减，强制玩家"持续施压"而非"等机会"。这是"主动进攻驱动"的设计手段

### 7.3 可改进点

1. **下限门槛过高**：几乎没有逃课路径，手残玩家可能卡关流失。可在简单难度中提供"弹刀窗口放宽"的辅助
2. **Build 多样性缺失**：虽然聚焦核心体验，但长线游玩时缺乏 build 探索乐趣。可考虑在 DLC 中加入有限 build
3. **危字提示过于明显**：红色"危"字提示让读招门槛降低，硬核玩家可能觉得"过于保姆"。可在高难模式中关闭危字提示

## 9. 结论与一页纸总结

**核心发现**：

1. **弹刀是攻防枢纽**：完美格挡同时是防御和进攻——累积敌方躯干值。这是"防御即攻击"的设计典范
2. **双向躯干值是精准驱动**：躯干值双向流动，强制玩家精准弹刀而非无脑格挡。这是"硬核精准判定"的设计模板
3. **危字差异化应对是读招深度**：三类危字强制玩家"读懂招式"而非"统一应对"
4. **做减法聚焦核心体验**：砍掉 Build 多样性，把所有注意力聚焦在"一刀一弹"上。这是"少即是多"的设计哲学

**对我们项目的 3 条可借鉴启示**：

1. **防御即进攻**：让防御动作（格挡/闪避）同时获取资源或造成伤害，把防御从"被动保命"升级为"主动积累"。这是手感差异化的关键设计
2. **双向资源做精准驱动**：让防御资源双向流动（玩家也在被累积），强制精准操作而非无脑防御。适合硬核定位的 ARPG
3. **做减法聚焦核心**：如果项目定位硬核，砍掉 Build 多样性，把所有注意力聚焦在核心机制上。少即是多
