照夜炼器 · 跨设备开发接续说明
版本：网页原型 web-0.1；归档日期：2026-11-19

一、最新主线与打开入口
当前优先工作的是本文件夹的网页版灵剑原型，不是此前Unity工程。
用户已决定先验证“从原材料到最终锻造成品”的手动炼器体验。
只做：选料 → 控火熔炼 → 七锤塑形 → 连通阵纹 → 淬火 → 成品鉴定。
不做：委托、采购、货币、宗门经营、弟子AI、战斗、Steam接入。
世界观仍为东方玄幻炼器宗门；本轮只截取其中的制造流程。

在另一台电脑：
1. 获取仓库最新版本，打开“灵剑炼器_网页版原型”文件夹。
2. 双击 index.html，或在Edge/Chrome中打开该文件。正常游玩不需要Node、Unity、账号或联网。
3. “照夜炼器_可玩原型.html”是同源码的便利交付副本；开发只修改 index.html，交付前同步副本。
4. GitHub网页展示HTML源码，不是在线游戏托管；请下载文件或仓库后在浏览器打开。

二、文件与工作职责
index.html：唯一可维护的游戏源码，HTML、CSS、JS、SVG和Canvas绘制全部在此；没有遗漏的图片、字体、音频或外部JS。
照夜炼器_可玩原型.html：已交付用户的同版本单文件副本。
package.json / package-lock.json：仅供开发验证使用，固定Playwright Core 1.62.1；不是网页运行依赖。
tests/browser.cjs：跨平台真实浏览器回归，默认从本项目定位index.html，不再依赖原机器的私有目录。
tests/check-handoff.cjs：仅用Node内置模块核对交付清单、SHA-256、两个HTML的一致性及历史测试证据。
Verification/final_browser_report.json：原始最终31项浏览器报告的移植版，保留各用例、输入事件、统计及结果，仅将主机路径转换为项目相对路径。
Verification/test_summary.json：便于快速查看的统计、材料方案和成品结果。
Verification/screenshots/：最终测试的10张桌面/手机截图。
Verification/samples/：测试实际导出的青纹灵剑JSON样例，不是玩家存档或设计定义。
交付文件清单.json：本文件夹其余交付文件的大小与SHA-256；清单自身不递归列入。

三、可复现的开发验证
需要Node.js 22或以上与Chromium系浏览器。当前已实测Node 24.18.0、Playwright Core 1.62.1、Edge 157.0.4341.60。
在本文件夹的终端执行：
  npm run check
这只核对文件，不启动游戏、不下载依赖。

执行完整浏览器回归：
  npm ci --ignore-scripts --no-audit --no-fund
  npm test
Windows会尝试已安装的Edge/Chrome；macOS/Linux也会寻找常见浏览器路径。
如果自动定位不到，可将环境变量 FORGE_BROWSER_PATH 设为实际浏览器可执行文件，再执行 npm test。
如果没有可用浏览器，并希望使用Playwright管理的Chromium，可自行执行：
  npx playwright-core install chromium
该命令会下载浏览器，仅开发测试需要；普通游玩不需要。

可选环境变量：
FORGE_HTML_PATH：需测试的HTML，默认本项目index.html。
FORGE_TEST_OUTPUT：新报告输出目录，默认本项目test-results。
FORGE_BROWSER_PATH：已有浏览器可执行文件路径。
PLAYWRIGHT_MODULE_PATH：仅供已有受控测试环境复用现成模块，普通设备留空即可。
每次测试输出唯一报告/截图，不覆盖历史证据。新增test-results和node_modules已被.gitignore排除。
不要更改或绕过系统执行策略、许可证、防火墙或网络证书检查；权限拒绝应如实记录。

五、现行工艺规则（均为原创原型参数）
主材：青纹铁熔炼温区62—78，偏稳固；玄寒铁68—76，偏锋锐。
辅材：引灵银加强导灵，熔炼温区两侧各收窄2。每次只选一种主材，辅材可不加。
熔炼：14秒，温区内累计时长占比四舍五入成为得分；风门0—100%，初始温度30。
温度公式：T新＝限制到0—100[T旧＋(40×风门比例−0.28×(T旧−22))×时间步长]。
保持温度的参考风门：0.28×(目标中心−22)÷40。
锻形：7锤，摆动游标入绿色区时点击/空格；目标每锤变化，约0.28秒冷却，长按不连打。
阵纹：6节点，青纹铁依次0→1→2→3→4→5；玄寒铁0→1→3→2→4→5。UI显示符字和先后顺序。
错序每次扣12，正常分100；可重描一次，清掉错序但保留8分损耗，重描最高92。
淬火：出炉温度95，每秒下降10，7秒内不入水计0；青纹铁入水温区48—60，玄寒铁50—56；区内100，区外每偏差1扣3。
总分：熔炼30%＋锻形30%＋阵纹20%＋淬火20%，四舍五入。
品质：80以上灵品，50—79良品，低于50瑕品。熔炼/淬火低于30，总分封顶49；锻形/阵纹低于30，封顶79。
最终属性是材料基础与工艺得分的相对标尺，锋锐/稳固/导灵均0—100，不等同于战斗伤害。

六、目前的技术边界
静态单页、纯JavaScript、无服务端、无数据库、无外部素材请求。
未使用localStorage或sessionStorage；进度仅在内存，刷新即重置。
结果页可下载本炉JSON记录，但没有读入该JSON恢复进度的功能。
音效默认关闭，由用户点击启用Web Audio；声音也由代码产生，无音频文件依赖。
所有计时工序必须手动开始；切换窗口暂停，返回需手动继续。
所有失误都允许最终成器，严重失误会显示暗裂/器性缺陷；不将失败直接变成终止画面。
不要把测试生成的样例JSON误当配置，不要把浏览器验证用的只读snapshot接口当游戏自动成功入口。
