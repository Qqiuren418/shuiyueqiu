# 第一编 · 世界观架构

## 一、三层世界总览

世界不是一层。表层的凡域只是水面，水下还有两层更深、更古老、更危险的秩序。

| 层级 | 名称 | 别称 | 核心特征 | 与上层关系 |
|---|---|---|---|---|
| 表层 | 凡域 | 现实/阳间 | 普通人生活的现代世界，异常被屏蔽 | 水面之上 |
| 里层 | 隐域 | 折叠世界/暗市 | 异常活跃的平行空间，有独立社会结构 | 水面之下，通过折叠点与凡域连通 |
| 深层 | 源域 | 本源之地/倒悬之境 | 异常的本源之地，规则扭曲 | 隐域的根基，异常的源头 |

### 三层世界的模型

```
        凡域（普通人感知的现实）
     ════════════════════════════  ← 屏障·"穹顶"
        隐域（异常活跃的折叠空间）
     ════════════════════════════  ← 屏障·"根须"
        源域（异常本源·规则扭曲之地）
```

三层之间不是物理上的"上下"，而是维度上的嵌套。凡域在最外层，隐域折叠在凡域的缝隙中，源域则是一切异常力量的根。

## 二、凡域 · 表层世界

### 2.1 定义

凡域是普通人感知的现实世界。你看到的城市、街道、人群、手机信号、外卖小哥——这些都是凡域。异常在凡域中存在，但被守夜局等组织屏蔽，普通人无法感知。

### 2.2 屏障机制

凡域与隐域之间存在一层屏障，术语称"穹顶"。

穹顶不是物理实体，是一种**规则级屏障**——源域的规则在穹顶处发生衰减，异常力量到达穹顶时会被大幅削弱，残余的渗漏物才是凡域中出现的"异常事件"。

**穹顶的厚度不均匀**：
- 人口密集处穹顶厚（集体认知强化屏障）
- 荒野、废墟、旧建筑处穹顶薄（异常容易渗漏）
- 特殊历史节点（战争、灾难现场）穹顶有裂缝

### 2.3 凡域中的异常表现

异常渗漏进凡域后，表现就是"无法用常理解释的事件"——倒走的钟、时间错位的居民楼、消失又出现的地铁乘客。这些就是守夜局收容的对象。

普通人接触异常后会出现两种反应：
- **认知屏蔽**：大脑自动修正记忆，把异常解释为"记错了""做梦""错觉"
- **亲和残留**：少数人有微弱的异常亲和度，能短暂保留记忆，但会在6小时内消散

沈渊的0.87亲和度，远超常人，所以他的记忆不会被屏蔽——这是他入选守夜局的核心原因。

## 三、隐域 · 里层世界

### 3.1 定义

隐域是异常活跃的平行空间，折叠在凡域的缝隙中。这里有独立的地理、社会、经济和法律。普通人无法进入，需要通过折叠点或特殊手段。

### 3.2 隐域的地理

隐域不是凡域的"镜像"，而是一片有自己规则的大陆。主要区域：

| 区域 | 名称 | 特征 | 控制势力 |
|---|---|---|---|
| 中心区 | 暗市 | 隐域最大的交易与社交中心，所有势力共管的"中立区" | 五势力共管 |
| 北区 | 锈原 | 工业废墟风格，异常物产丰富，黑市聚集地 | 维序会名义管辖，实际军阀割据 |
| 东区 | 纸楼 | 民居迷宫，信息黑市，情报交易地 | 渊阁影响区 |
| 南区 | 血渊 | 高危险区，野生异常密集，禁止低阶者进入 | 无势力控制，野外区 |
| 西区 | 暮城 | 神秘学风格，归源教派总部所在 | 归源教派 |
| 地下 | 倒悬之境入口 | 源域的入口之一，被最高级别封印 | 守夜局重兵把守 |

### 3.3 隐域的社会

隐域有独立的居民——"隐域住民"。他们不是异常，是长期生活在隐域中的人类后裔，血脉中有微弱的异常亲和，能感知隐域规则。隐域住民约有数十万，有自己的货币（"源币"，以异常残片为本位）、法律（各势力在自己地盘执行自己的法）和等级（按血脉亲和度分1-9级）。

### 3.4 隐域与凡域的连通：折叠点

折叠点是凡域与隐域之间的"通道"。它不是固定的门，而是规则薄弱处自然形成的裂口。

**折叠点分级**（对应异常等级）：

| 等级 | 名称 | 规模 | 持续时间 | 影响范围 |
|---|---|---|---|---|
| 一级 | 微隙 | 单一物体异常 | 数分钟-数小时 | 物体本身 |
| 二级 | 裂口 | 局部空间异常 | 数小时-数天 | 一栋楼/一条街 |
| 三级 | 汇流 | 区域性异常 | 数天-数周 | 一个城区 |
| 四级 | 溢界 | 大规模折叠点开启 | 数周-数月 | 整座城市 |
| 五级 | 归源 | 源域直接渗漏 | 不可预测 | 不可预测 |

## 四、源域 · 深层世界

### 4.1 定义

源域是异常的本源之地，一切异常力量的源头。它不是"地狱"或"魔界"，而是**规则的源头**——所有血脉、所有异常、所有规则扭曲的力量，最终都来自源域。

### 4.2 源域的性质

源域没有固定的地理形态。它是一片**规则扭曲的混沌区域**，时间和空间在这里没有意义。

- **时间异常**：源域的时间流速与凡域不同，可能快、可能慢、可能倒流、可能停滞
- **空间异常**：源域的空间是非欧几里得的，直线会弯曲，远处可能比近处更近
- **规则异常**：源域的物理规则与凡域不同——重力可能向上、水可能往高处流、火焰可能冻结

### 4.3 源域的核心结构

源域不是一片混沌，它有结构——一种被原初血脉者才能感知的结构。

```
        ┌─ 原初之海 ─ 规则的原始形态，无始无终
        │
        │   ┌─ 倒悬之树 ─ 连接源域与隐域的"轴"
        │   │
        │   │   ┌─ 原型场 ─ 每种血脉/异常的"原型"所在
        │   │   │   （战原型、灵原型、御原型、源原型、原初原型）
        │   │   │
        │   │   └─ 残响之厅 ─ 古老存在的回声，源域的"记忆"
        │   │
        │   └─ 永暮之城 ─ 源域意志的显现处
        │
        └─ 虚空边界 ─ 源域的边缘，无人知晓外面是什么
```

### 4.4 源域意志

源域不是无主的。它有一种**意志**——不是神，不是人，是一种规则级的、自然而然形成的"倾向"。

源域意志的核心目的：**回收所有渗漏到凡域的力量**。

所有异常都是源域力量的"渗漏物"，源域意志在缓慢地、持续地"拉"它们回去。这就是异常会活性化、封印会渗漏的根本原因——源域在召唤。

沈渊作为"原初遗脉"的继承者，本质上是源域在凡域的"种子"——他的血脉是源域力量在凡域的合法载体。这就是他能深度收容异常而不异化的原因：他不是在"吸收"异常，是在让异常"回家"。

### 4.5 源域的终极秘密（系列终局留白）

源域之上是否还有更高的存在？源域意志本身是不是某种造物？规则之上是否还有规则？

**这些问题在全书终局不回答**。留作改编产品的外延空间。

## 五、异常的本质

### 5.1 异常是什么

异常不是怪物，不是鬼，不是外星人。异常是**源域力量渗漏到凡域后形成的凝聚体**。

每种异常都对应源域中的一种"原型"力量。倒悬之钟对应的是"时间原型"，居民楼的错位对应的是"空间原型"，地铁乘客的记忆替换对应的是"意识原型"。

### 5.2 异常的分类

| 类别 | 对应原型 | 典型表现 | 收容方式 |
|---|---|---|---|
| 时序型 | 时间原型 | 时间倒流、时间错位、时间冻结 | 御脉封印+灵脉稳定 |
| 空间型 | 空间原型 | 折叠空间、空间错位、无限回廊 | 御脉锚定+战脉突破 |
| 意识型 | 意识原型 | 记忆篡改、幻觉、精神干扰 | 灵脉净化+御脉隔离 |
| 物质型 | 物质原型 | 物体异变、异常生命体 | 战脉压制+御脉封印 |
| 规则型 | 规则原型 | 物理法则扭曲（重力反向等） | 需归源级收容 |
| 原初型 | 原初原型 | 直接源域渗漏，最高危 | 仅原初血脉可收容 |

### 5.3 异常的"活性"

异常不是死的，是活的。每个异常都有自己的"活性周期"——休眠、苏醒、活性化、高潮、衰退。

封印的本质是"压制活性"，让异常保持休眠状态。但封印会随时间衰减，需要定期"充能"。这就是守夜局的日常工作——巡查已封印的异常，充能封印，处理新活性化的异常。

## 二、守夜局

### 2.1 基本信息

| 项目 | 内容 |
|---|---|
| 全称 | 守夜人局·异常收容与隐匿控制委员会 |
| 性质 | 半官方组织，名义上隶属国务院应急办，实际独立运作 |
| 总部 | 每个一线城市设一处，称"第X处"。江城为第七处 |
| 编制 | 全国约3000人，外勤与内勤比约6:4 |
| 立场 | 收容异常，隐匿控制，防止普通人知晓异常存在 |
| 意识形态 | "异常不是武器，不是神迹，是需要被锁起来的危险品" |

### 2.2 组织结构

```
守夜局局长
    │
    ├── 研究部 ── 异常分析、封印技术研发、血脉检测
    │
    ├── 收容部 ── 外勤收容行动，分A/B/C三组
    │     │
    │     ├── A组（高阶觉醒者，处理汇流级以上）
    │     ├── B组（中阶觉醒者，处理裂口级）
    │     └── C组（低阶觉醒者，处理微隙级）
    │
    ├── 档案部 ── 异常档案管理（沈渊所在部门）
    │
    ├── 监测部 ── 折叠点监测、预警系统
    │
    └── 内务部 ── 内部审查、叛徒追查
```

### 2.3 守夜局的灰色面

守夜局不是纯善的组织。它的核心目标是"隐匿控制"，为此会做很多灰色操作：

- **对知情普通人的记忆清除**：不自愿，强制执行
- **对异常的人体实验**：研究部有秘密项目，用异常残片在觉醒者身上做强化实验
- **对隐域住民的歧视**：视隐域住民为"半异常"，限制其进入凡域
- **对叛徒的处置**：泄露异常信息者，记忆清除+永久收容，不审判

### 2.4 守夜局内部派系

| 派系 | 主张 | 代表 | 与主角关系 |
|---|---|---|---|
| 保守派 | 维持现状，隐匿优先 | 陆青衡 | 沈渊的保护者 |
| 研究派 | 利用异常，强化战力 | 研究部主任·方既白 | 想研究沈渊的血脉 |
| 鹰派 | 主动出击，消灭异常 | A组组长·霍正 | 视沈渊为潜在威胁 |

## 三、维序会

### 3.1 基本信息

| 项目 | 内容 |
|---|---|
| 全称 | 维序者联合会 |
| 性质 | 官方背景的组织，隶属国家安全部，有军事力量 |
| 总部 | 维序塔（隐域中心区） |
| 编制 | 全国约5000人，含一支300人的"维序军" |
| 立场 | 秩序至上，异常必须被国家控制，不能由守夜局这种"半民间"组织说了算 |
| 意识形态 | "异常是国家资源，必须服务于国家利益" |

### 3.2 维序会与守夜局的矛盾

两个组织都主张"隐匿控制异常"，但权力归属有冲突：
- 守夜局认为自己更专业，有传承，不该被官僚控制
- 维序会认为守夜局是"民间组织"，不可控，异常应该由国家管

矛盾在日常中表现为：抢收容物、争夺管辖权、互相渗透情报、偶尔火拼。

### 3.3 维序会的灰色面

- 视异常为"资源"，会主动制造异常武器
- 对隐域住民实行"登记管制"，视其为二等公民
- 有"清洗派"存在，主张消灭所有异常亲和者以绝后患

### 3.4 维序会内部派系

| 派系 | 主张 | 与主角关系 |
|---|---|---|
| 务实派 | 利用异常，服务国家 | 想招募沈渊 |
| 清洗派 | 消灭所有异常亲和者 | 视沈渊为必须清除的目标 |
| 改革派 | 与隐域住民共存 | 潜在盟友 |

## 四、归源教派

### 4.1 基本信息

| 项目 | 内容 |
|---|---|
| 全称 | 归源教派 |
| 性质 | 宗教式组织，崇拜源域，主动引源 |
| 总部 | 永暮之城（隐域西区） |
| 编制 | 核心成员约500人，信徒（含隐域住民）约数万 |
| 立场 | 异常是"神的恩赐"，源域是"故乡"，主动打开折叠点迎接源域力量 |
| 意识形态 | "源域是真实的故乡，凡域是牢笼，我们要回家" |

### 4.2 归源教派的核心理念

归源教派不认为自己是邪恶的。他们的核心信仰是：
- 凡域是"牢笼"，人类被困在这里
- 源域是"故乡"，是更真实、更高级的存在
- 异常是源域给凡域的"信号"，应该被拥抱而非封印
- 打开折叠点=打开回家的大门

### 4.3 归源教派的组织

```
教主（源脉·归源阶段，神秘存在）
    │
    ├── 四大执事 ── 分管东南西北四区
    │
    ├── 引源众 ── 专门制造折叠点的行动部队
    │
    ├── 讲道众 ── 传教、招募新信徒
    │
    └── 护教众 ── 战斗部队
```

### 4.4 归源教派的悲悯面

归源教派不是疯子组织。他们中间有真心相信"回归源域"的人——尤其是那些在凡域受尽苦难的人，对他们来说，源域是唯一可能的救赎。

裴夜（中期主敌）就是这样一个"悲悯反派"——他真心相信引源是拯救人类。

## 五、渊阁

### 5.1 基本信息

| 项目 | 内容 |
|---|---|
| 全称 | 渊阁 |
| 性质 | 远古传承的隐秘组织，比守夜局和维序会都古老 |
| 总部 | 倒悬之树·渊阁本部（位于隐域与源域的交界处） |
| 编制 | 核心成员约100人，均为高阶觉醒者 |
| 立场 | 守护历史，封锁源域，阻止源域力量渗漏 |
| 意识形态 | "我们是看守者，不是守护者。我们看守的，是源域的门" |

### 5.2 渊阁的特殊性

渊阁与其他势力最大的不同：它**不收容异常，不利用异常，不消灭异常**。它只做一件事——**看守源域的入口**。

渊阁三千年前由沈望舒的先祖创建。创始者从源域带出了一颗"原初种子"——这就是原初遗脉的源头。渊阁的使命就是看守这颗种子，不让源域召回它，不让任何人用它打开源域的大门。

### 5.3 渊阁的组织

```
阁主（原初血脉·归源阶段）
    │
    ├── 守卷人 ── 保管源域残卷和渊阁三千年的历史记录
    │
    ├── 守门人 ── 看守已知的源域入口
    │
    ├── 行路人 ── 在凡域和隐域游走，收集情报，寻找渗漏
    │
    └── 传脉人 ── 负责传承原初遗脉（沈望舒是末代传脉人）
```

### 5.4 渊阁的困境

渊阁三千年传承，到沈望舒这一代已经几乎断绝：
- 成员老龄化，新成员越来越少
- 源域入口越来越多，看不过来
- 原初遗脉的继承者（沈渊）被藏在凡域，不知情
- 守夜局和维序会都不知道渊阁的真正目的

## 六、源域残响

### 6.1 定义

源域残响不是一个组织，是**源域意志的具象化表现**。

当源域意志"关注"到某处时，会在那里形成一种"残响"——规则扭曲的余波。这不是有意识的行动，是源域力量自然流动时的"涟漪"。

### 6.2 源域残响的表现

- 折叠点自然开启（源域在"拉"力量回去）
- 异常活性化频率上升（源域力量在增强）
- 觉醒者的血脉共鸣加剧（源域在呼唤血脉）
- 原初血脉者的觉醒加速（源域在召回种子）

### 6.3 源域意志的目的

源域意志只有一个目的：**回收所有渗漏的力量，包括原初种子**。

沈渊的存在，对源域意志来说是"最大的渗漏"——原初遗脉是源域力量在凡域的合法载体。源域意志会持续地、缓慢地"拉"沈渊回归。

这就是"登神悖论"的本质——登神不是"升级"，是"被源域召回意志"，失去自我。

# 第三编 · 修炼体系与七阶境界

## 一、血脉体系总览

### 1.1 血脉品阶（先天底数）

血脉品阶决定一个人的修炼上限和方向。品阶越高，潜力越大。

| 品阶 | 稀有度 | 觉醒上限 | 特征 |
|---|---|---|---|
| 凡骨 | 99%的人 | 不可觉醒 | 无异常亲和 |
| 残血 | 1% | 最多凝相 | 微弱亲和，可做内勤 |
| 醒血 | 0.1% | 最多化形 | 中等亲和，主力外勤 |
| 王血 | 0.01% | 最多归源 | 高亲和，精英 |
| 神血 | 0.001% | 可神临 | 顶级天赋 |
| 原初 | 唯一 | 无上限 | 源域直接遗脉 |

### 1.2 血脉方向（五脉）

血脉品阶决定上限，血脉方向决定能力类型。

| 方向 | 能力特征 | 战斗定位 | 原型 |
|---|---|---|---|
| 战脉 | 物理强化、爆发、近战 | 突进DPS | 力量原型 |
| 灵脉 | 感知、精神、幻术、情报 | 控场/辅助 | 意识原型 |
| 御脉 | 防御、封印、结界、控制 | 坦克/封印师 | 空间原型 |
| 源脉 | 规则干涉、时空 | 隐藏职业 | 规则原型 |
| 混脉 | 多脉融合 | 特殊build | 原初原型 |

普通人的血脉是单一方向的。混脉（多血脉融合）只存在于原初血脉者身上——因为只有源域原型能融合所有血脉而不冲突。

### 1.3 觉醒阶段（后天修炼）

觉醒阶段决定当前战力。从1到7：

```
1. 沉眠 → 2. 初觉 → 3. 通脉 → 4. 凝相 → 5. 化形 → 6. 归源 → 7. 神临
```

## 二、七阶境界详解（实力表现对比）

### 第一阶 · 沉眠

**定义**：血脉未醒，只有异常亲和体质。

**实力表现**：
- 无法主动使用任何血脉能力
- 对异常有天然的感知和抗性，但只能被动触发
- 普通人中的"敏感者"，但不具备任何战斗能力
- 可以使用封印工具（如封印环），但只能执行预设程序，无法自创封印

**实战能力**：
- 面对微隙级异常：能感知、能记录、能使用工具辅助收容，但无法独力收容
- 面对裂口级异常：无任何战斗能力，只能撤离
- 面对普通人：与普通人无异

**代表场景**：沈渊在黄金三章中的状态。他能发现倒走的钟、能记得墨水消失的内容、能在E-0208面前感到左眼疼痛——但这些都是被动触发，他无法主动控制。

**与高一阶的差距**：沉眠者面对初觉者毫无胜算。初觉者的被动身体强化已经超出了凡人极限。

---

### 第二阶 · 初觉

**定义**：血脉第一次主动反应，被动能力开始稳定化。

**实力表现**：
- 身体素质开始超越常人——力量、速度、反应约为常人的2-3倍
- 血脉方向的被动能力稳定：战脉者体质强化、灵脉者感知范围扩大、御脉者封印亲和提升
- 无法主动释放血脉之力，但被动反应更快更准
- 可以使用低级封印工具并略加引导

**实战能力**：
- 面对微隙级异常：可独力收容（借助工具）
- 面对裂口级异常：在团队中可承担辅助角色
- 面对普通人：一对一轻松胜出，但一对多仍吃力

**代表场景**：秦落的日常状态。她是战脉初觉，身体素质明显超出常人——能徒手掰弯钢筋、从三楼跳下无碍——但还没有"技能"，只是"身体素质强"。

**与高一阶的差距**：初觉者面对通脉者会被碾压。通脉者已能主动释放血脉之力，形成"技能"，质变。

---

### 第三阶 · 通脉

**定义**：主动引导血脉之力，形成固定能力。这是"质变"的一阶——从"体质强化"到"技能释放"。

**实力表现**：
- 主动释放血脉之力，形成稳定技能
- 战脉者可瞬移斩击（裂空），近战能力质变
- 灵脉者可主动感知异常结构（灵视），可读取情报
- 御脉者可展开结界防御（御界），可主动封印
- 身体素质约为常人的5-8倍
- 可使用中级封印工具并自主调整

**实战能力**：
- 面对微隙级异常：轻松独力收容
- 面对裂口级异常：可独力收容
- 面对汇流级异常：在团队中承担核心角色
- 面对普通人：可一对十以上

**代表场景**：秦落在卷二的状态。她学会了"裂空"——短距离瞬移斩击，能一刀切开异常物的外壳。这是真正的"超能力"了。

**与高一阶的差距**：通脉者面对凝相者会被碾压。凝相者的"相"是血脉外放成型，相当于从"刀"升级到"战争机器"。

---

### 第四阶 · 凝相

**定义**：血脉之力凝成"相"，可外放战斗。"相"是血脉能量的实体化形态。

**实力表现**：
- 血脉能量实体化，形成"相"——战相（武器/武者形态）、灵相（精神体）、御相（结界形态）
- 战脉者可凝出"战相·血怒"——一个能量化的战斗形态，大幅强化攻击
- 御脉者可凝出"御相·十方"——一个大范围封印结界
- 灵脉者可凝出"灵相·千丝"——精神干涉，可制造幻术
- 身体素质约为常人的10-20倍
- 可使用高级封印工具并自创简单封印

**实战能力**：
- 面对裂口级异常：独力收容，轻松
- 面对汇流级异常：可独力收容（吃力）
- 面对溢界级异常：在团队中承担主力
- 对低阶觉醒者：碾压优势

**代表场景**：陆青衡的实力。他是御脉凝相，可以展开"御相·十方"——一个覆盖整个街区的封印结界，能同时压制多个裂口级异常。在守夜局第七处，他是绝对的战力天花板。

**与高一阶的差距**：凝相者面对化形者胜算极低。化形者的血脉已能化形，与异常共生——这意味着异常对他们几乎无效。

---

### 第五阶 · 化形

**定义**：血脉化形，可与异常共生。这是"超凡入圣"的一阶——觉醒者从"使用血脉之力"变成"成为血脉本身"。

**实力表现**：
- 血脉能量不再外放为"相"，而是融入自身，形成"化形态"
- 战脉者可化为"战形·渊噬"——身体局部或全部能量化，刀枪不入，攻击力质变
- 御脉者可化为"御形·锁源"——封印之力融入自身，自身即是封印
- 灵脉者可化为"灵形·溯源"——精神力可短暂脱离肉体，直接接触异常原型
- 身体素质约为常人的50-100倍
- 深度收容不再有裂纹风险（对化形者而言）
- 可自创封印术

**实战能力**：
- 面对汇流级异常：独力收容，轻松
- 面对溢界级异常：可独力收容
- 面对归源级异常：在团队中承担核心
- 对低阶觉醒者：降维打击

**代表场景**：归源教派四大执事中的强者。他们可以化形战斗——身体部分变成能量态，免疫物理攻击，只有同阶或更高阶的血脉之力才能伤到他们。守夜局全国能达到化形的不到50人。

**与高一阶的差距**：化形者面对归源者完全无法抵抗。归源者已触及规则层面，是"质"以上的差距。

---

### 第六阶 · 归源

**定义**：触及血脉本源，开始理解源域规则。这一阶的核心不是"更强的力量"，而是"理解规则"。

**实力表现**：
- 可调用源域力量，形成"原初技"——直接利用规则的攻击
- 战脉归源者："原初战"——攻击不靠力量，靠"规则重写"（让敌人的防御规则失效）
- 御脉归源者："原初封"——封印不是压制，是"规则改写"（让异常的存在规则被改写）
- 灵脉归源者："原初视"——看穿规则本质，可直接读取异常的原型
- 身体素质已不能用倍数衡量——速度接近瞬移，力量可摧毁街区
- 可自创规则级封印

**实战能力**：
- 面对溢界级异常：独力收容
- 面对归源级异常：独力收容（吃力）
- 对化形及以下：瞬杀
- 开始面临"登神诱惑"——源域意志会主动接触

**代表场景**：归源教派教主、渊阁阁主、守夜局局长——全国能达到归源的，不超过10人。他们之间的战斗不是"对轰"，是"改规则"——谁先改成功，谁就赢。

**与高一阶的差距**：归源者面对神临者无法抵抗。神临者已近神格，是"规则本身"。

---

### 第七阶 · 神临

**定义**：几近神格，站在登神的临界点。这一阶的核心矛盾是"登神诱惑"——继续前进就是登神，但登神=失去自我。

**实力表现**：
- 自身成为规则的一部分——不再使用规则，而是"是"规则
- 神临者可以在局部范围内改写物理法则
- 战脉神临者：一击可摧毁一座城市
- 御脉神临者：可永久封印一个区域，使其规则完全改变
- 灵脉神临者：可读取所有人的记忆，可改写认知
- 原初血脉神临者：可直接开启归源级折叠点，连通源域
- 面临登神悖论——情感开始剥离，源域意志持续召唤

**实战能力**：
- 面对归源级异常：独力收容，轻松
- 对归源及以下：不可战胜
- 核心矛盾：战斗越强，离登神越近，离失去自我越近

**代表场景**：全书没有任何角色在正传中达到神临。沈渊在卷七达到"神临门槛"——站在临界点，面临终极抉择。

---

### 终极 · 登神

**定义**：超越神临，被源域同化，成为规则的一部分。

**登神=失去自我**。登神者不再是"人"，是源域意志的一部分。他们拥有无尽的力量，但不再有"我"的概念。

登神不是一个"升级选项"，是一个"陷阱"——源域意志诱导所有神临者登神，因为登神=回归源域=源域回收了自己的力量。

**沈渊的第三条路**：既不登神（保留自我），也不自毁（保留力量），而是成为"第三极"——凡域与源域之间的"桥"，一种新的存在形态。

## 四、修炼路径与资源

### 4.1 常规修炼路径

普通人 → 亲和度检测 → 守夜局/维序会招募 → 训练（基础体术+封印工具使用）→ 初觉 → 通脉（需要3-5年）→ 凝相（需要10-15年）→ 化形（需要30-50年，多数人到不了）→ 归源（少数）→ 神临（极少数）

### 4.2 沈渊的特殊路径

沈渊不走常规路径。他的修炼方式是**深度收容即修炼**——通过收容异常，激活血脉中的对应原型，实现快速觉醒。

| 阶段 | 常规修炼时间 | 沈渊的收容修炼时间 |
|---|---|---|
| 沉眠→初觉 | 1-3年 | 约3个月（卷一末-卷二初） |
| 初觉→通脉 | 3-5年 | 约6个月（卷二-卷三） |
| 通脉→凝相 | 10-15年 | 约1年（卷三-卷四） |
| 凝相→化形 | 30-50年 | 约1年（卷四-卷五） |
| 化形→归源 | 多数人到不了 | 约1年（卷五-卷六） |
| 归源→神临 | 几乎不可能 | 约1年（卷六-卷七） |

**代价**：快速觉醒=快速接近登神=快速失去自我。沈渊的修炼速度越快，情感剥离越严重。

### 4.3 收容即修炼的机制

```
异常出现 → 收容行动 → 普通收容（封印异常）
                    → 深度收容（沈渊独有：吸收异常原型）
                         → 血脉共鸣触发
                         → 激活对应血脉片段
                         → 觉醒进阶
                         → 裂纹值+1（代价）
```

### 4.4 裂纹值系统

| 裂纹值 | 状态 | 影响 |
|---|---|---|
| 0 | 正常 | 无影响 |
| 1-3 | 轻度溢化 | 偶发感知过载，可控制 |
| 4-6 | 中度溢化 | 情感波动加剧，需要净化 |
| 7-9 | 重度溢化 | 局部失控，身体出现异常特征 |
| 10+ | 临界 | 接近登神，情感严重剥离 |
| ? | 登神 | 失去自我 |

净化方式：低烈度收容（吸收微隙级异常不深度收容，可降低裂纹值）、渊阁的净化仪式、与羁绊者的人类情感接触。
