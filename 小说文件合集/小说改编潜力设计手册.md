# 《你的小说》改编潜力设计手册
# 面向 ARPG / MMORPG / 世界级影视IP 的世界观架构方案

> 设计哲学：**一个设定，三种用法**。每个世界观要素在小说、游戏、影视中各有承载，而非为单一媒介硬塞。

---

## 第零层 · 反向拆解：顶级IP的改编潜力来自什么

在动手设计前，先看哈利波特和漫威做对了什么：

| 能力维度 | 哈利波特 | 漫威宇宙 | 你要学的本质 |
|---|---|---|---|
| 世界观层级化 | 魔法世界藏在现实之后 | 多元宇宙+街头-宇宙分层 | 表-里-深三层世界 |
| 力量体系符号化 | 四学院+魔杖+咒语 | 超能力+装备+科技 | 标签化、可视化、可收集 |
| 势力矩阵化 | 四学院+分院帽的选择 | 数十阵营动态结盟对抗 | 阵营归属+道德光谱 |
| 角色可拓展性 | 黄金三角+次世代 | 蜘蛛侠/奇异博士各自独立电影 | 每个角色都能开外传 |
| 地标可识别 | 霍格沃茨/对角巷/古灵阁 | 复仇者大厦/瓦坎达 | 每个势力有视觉锚点 |
| 神秘感留白 | 魔法规则不解释到底 | 宇宙总有更高存在 | 规则清晰但天花板未知 |
| 成长曲线可外延 | 七年学业=七部曲 | 英雄之旅阶段性升级 | 清晰的境界=清晰的季/版本 |

**改编潜力的本质 = 体系化程度 × 视觉符号密度 × 阵营冲突复杂度 × 留白空间**

你的收容异常+血脉传承方向，天然契合。下面逐层设计。

## 第一层 · 世界观架构：三层世界+收容折叠

### 设计原则（改编导向）

- **ARPG需要**：线性关卡流、Boss设计空间、装备驱动、技能树
- **MMORPG需要**：开放世界分区、阵营PVP、副本生态、经济系统、社交空间
- **影视宇宙需要**：视觉地标、角色可开外传、危机升级节奏、神秘留白
- **小说本身需要**：探索真相驱动、扮猪吃虎空间、升级爽感、伏笔回收

### 三层世界结构

```
┌─────────────────────────────────────────┐
│ 表层世界 · 凡域                          │  ← 影视S1、新手村、ARPG序章
│ 现代都市，普通人不知异常存在               │
│ 收容组织以"政府机构/基金会/研究院"身份隐藏  │
│ ↓ "第一次目击事件"作为切入点               │
├─────────────────────────────────────────┤
│ 里层世界 · 隐域                          │  ← 影视S2-3、MMO主城、ARPG中段
│ 异常活跃的平行空间/折叠城市/地下世界        │
│ 多势力公开博弈，普通人被屏蔽               │
│ 有自己的法律、经济、社会结构               │
│ ↓ "深渊事件"或"封印崩解"作为升级钩子        │
├─────────────────────────────────────────┤
│ 深层世界 · 源域                          │  ← 影视S4+、MMO资料片、ARPG终章
│ 异常的本源之地/血脉发源地/神话原型场域      │
│ 规则扭曲，存在层级之上还有层级              │
│ 主角最终要面对的"真相"所在                 │
└─────────────────────────────────────────┘
```

### 三层世界的改编映射

| 世界层 | 小说功能 | ARPG承载 | MMORPG承载 | 影视承载 |
|---|---|---|---|---|
| 凡域 | 扮猪吃虎舞台、日常+异常反差 | 序章教学关、都市关卡 | 新手村+主城周边 | S1日常奇观化 |
| 隐域 | 探索真相、势力交锋 | 中段大型关卡群、Boss战 | 核心地图、阵营主城、副本 | S2-3世界展开 |
| 源域 | 终极真相、血脉溯源 | 终章异界关卡、最终Boss | 资料片新大陆 | S4+宇宙级危机 |

### 关键设计：折叠点（异常发生器）

三层世界之间不是简单的"上下",而是通过**折叠点**连接——现实某处突然与源域接通，异常从中渗出。每个折叠点就是一个：
- **小说**：副本单元/收容任务/伏笔节点
- **ARPG**：关卡入口/Boss房间
- **MMORPG**：副本传送门/世界Boss刷新点/资料片衔接
- **影视**：单集危机/季终大事件/外传切入

折叠点分级：微隙（日常事件）→ 裂口（小型危机）→ 汇流（大型弧光）→ 溢界（跨季危机）→ 归源（系列终局）

**这个分级直接对应游戏副本分级和影视季的危机升级节奏。**

### 视觉地标清单（必备）

每个势力、每层世界都要有1-2个**可被立刻画出来的地标**，这是影视和游戏的视觉资产：

- 收容组织总部：一座伪装成博物馆/老洋房/地下医院的建筑（影视一眼识别）
- 隐域入口：某个城市广场的喷泉在特定时间倒流
- 源域地标：一棵倒悬生长在世界中心的树/一座永远在落日的城

## 第二层 · 修炼体系：血脉觉醒 × 异常收容 × 神格化进阶

### 设计原则

你的金手指是血脉/传承型，主角是高智冷静型，世界观是收容异常。修炼体系必须满足：

1. **可量化分级**（游戏数值、影视节奏刻度）
2. **技能可分支**（ARPG技能树、MMO职业分化、影视角色差异化）
3. **可视化符号**（影视特效、游戏UI、角色辨识）
4. **有天花板且天花板可被打破**（长篇升级+资料片空间）
5. **与异常体系深度绑定**（收容不只是战斗，是修炼方式）

### 体系骨架：血脉品阶 × 觉醒阶段 × 神格化

```
血脉品阶（先天底数，决定上限与特性方向）
  凡骨 → 残血 → 醒血 → 王血 → 神血 → 原初
   ↑                                                    ↑
  普通人                                              血脉源头

觉醒阶段（后天修炼，决定当前战力）
  沉眠 → 初觉 → 通脉 → 凝相 → 化形 → 归源 → 神临
   1     2      3      4      5      6      7

神格化（终极进阶，对应"封神"概念）
  归源之上，存在"登神"路径，但登神即异化，这是核心矛盾之一
```

### 七阶觉醒详解（直接对应游戏7个资料片/影视7季）

| 阶段 | 名称 | 核心变化 | 游戏化对应 | 影视化对应 |
|---|---|---|---|---|
| 1 | 沉眠 | 血脉未醒，只有异常亲和体质 | Lv1-10 新手期 | S1开篇，主角还不知道自己是谁 |
| 2 | 初觉 | 第一次血脉反应，被动能力觉醒 | Lv10-30 一转 | S1中段，第一次"奇观时刻" |
| 3 | 通脉 | 主动引导血脉之力，形成固定能力 | Lv30-60 二转/技能树展开 | S1终-S2初，能力定型 |
| 4 | 凝相 | 血脉凝成"相"，可外放战斗 | Lv60-100 三转/职业分化 | S2中后，战斗体系成熟 |
| 5 | 化形 | 血脉化形，可与异常共生 | Lv100+ 终局技能/资料片1 | S3，与异常关系深化 |
| 6 | 归源 | 触及血脉本源，开始理解规则 | 资料片2-3 | S4，真相浮出 |
| 7 | 神临 | 几近神格，但面临异化抉择 | 资料片4 终局 | S5+ 终极抉择 |

### 血脉分支：技能树×职业原型（ARPG/MMO双用）

血脉不只是强弱，还有**方向**。每个品阶的血脉觉醒后会走向不同的能力分支，这是游戏技能树和职业系统的天然基底：

| 血脉方向 | 能力特征 | ARPG定位 | MMO定位 | 影视角色原型 |
|---|---|---|---| 近战爆发 | 战士/刺客 | 突进DPS | 暴力型队友 |
| 灵脉 | 精神感知/幻术 | 法师/控场 | 控场/辅助 | 智囊型队友 |
| 御脉 | 防御/结界/封印 | 坦克 | 坦克/封印师 | 守护型队友 |
| 源脉 | 规则干涉/时空 | 隐藏职业 | 资料片职业 | 神秘外援 |
| 混脉 | 多血脉融合 | 混合职业 | 特殊build | 主角专属 |

**主角的"高智冷静"人设 + 混脉（多血脉融合）= ARPG多技能树自由搭配 + MMO多build流派 + 影视多能力呈现**

### 收容即修炼：核心差异化设计

**这是你这本区别于普通血脉流的关键**：血脉觉醒不只是打坐吸收，而是通过**收容异常**来反向激活血脉中的对应原型。

设计逻辑：
- 异常是源域力量的"渗漏物"，每种异常对应一种血脉原型
- 收容异常 = 接触原型 = 激活对应血脉片段
- 主角的金手指：能比其他人更"深"地收容异常而不被异化

**改编映射**：
- **ARPG**：打Boss→收容→获得新技能树节点（怪物图鉴=技能树）
- **MMO**：副本掉落不是装备，是"异常残片"，镶嵌进血脉槽→build变化
- **影视**：每收容一个异常=多一个视觉奇观+多一段角色弧光

### 登神悖论：核心矛盾留白

- 体系天花板"神临"之上还有"登神"
- 但登神=被源域同化=失去自我=变成最高级异常
- 主角的目标是走到神临，然后找到"不登神也超越"的第三条路

**这是整个系列的终极悬念，也是影视终局和游戏终局的核心冲突。**

## 第三层 · 势力组织架构：五力博弈 × 阵营光谱

### 设计原则

- **MMO需要**：3-5个可加入阵营，阵营PVP，阵营专属内容
- **ARPG需要**：敌对势力梯队，关卡主题分化
- **影视需要**：道德灰色地带，没有绝对反派，可开外传的反派阵营
- **小说需要**：扮猪吃虎的掩护身份，多方博弈的情报空间

### 五大势力矩阵

```
                      收容并研究异常
                            ↑
              【守序】←—— 守夜局 ——→【中立】
                              |
              隐匿控制        |
              ↓               |
    ┌─────────────────────────────────┐
    │  维序会      ←对抗→     异常阵营  │
    │  (政府背景)           (自然涌现)  │
    │  隐匿优先              存在优先   │
    └─────────────────────────────────┘
              ↑               ↑
              │               │
        秩序控制           自由共存
              ↑               ↑
    ┌─────────────────────────────────┐
    │  归源教派      ←利用→    渊阁     │
    │  (崇拜源域)          (远古传承)   │
    │  主动引源            历史守护     │
    └─────────────────────────────────┘
              ↓
          主动打开折叠点
              ↓
        【混沌】←—— 源域残响 ——→【混沌】
                      ↓
                   源域本源力量
```

### 五势力详解

| 势力 | 立场 | 道德光谱 | 主角关系 | 游戏阵营 | 影视定位 |
|---|---|---|---|---|---|
| 守夜局 | 收容研究，隐匿控制 | 守序中立 | 加入但保持独立 | 默认阵营，副本/任务发起点 | S1主舞台 |
| 维序会 | 政府背景，秩序至上 | 守序偏善/恶 | 亦敌亦友 | 对立阵营PVP | S2-3灰色对手 |
| 归源教派 | 崇拜源域，主动引源 | 混沌，但自认救世 | 中期主敌 | 资料片阵营 | S3主反派可开外传 |
| 渊阁 | 古老传承，历史守护 | 中立偏善 | 暗中盟友 | 中立阵营/资料片 | S4真相揭示者 |
| 源域残响 | 非组织，是源域本身的意志 | 超越道德 | 终极对峙 | 世界Boss/资料片终局 | S5+终极危机 |

### 阵营光谱的关键：道德灰色

每个势力都不能是纯善或纯恶：
- 守夜局收容异常但也做人体实验（黑历史）
- 维序会维护秩序但手段残酷（灰色对手）
- 归源教派想引源但部分成员有悲悯信念（反派有理）
- 渊阁守护历史但也隐瞒真相（盟友有秘密）
- 源域本身无善恶，是规则的自然力量（终极不可对话）

**道德灰色 = 影视可开外传 + MMO阵营可切换 + 小说情报反转空间**

### 主角的势力身份设计

**扮猪吃虎的最优解：主角明面是守夜局的低阶收容员，实则是混脉（多血脉融合）的隐性存在，暗中与渊阁有传承联系，最终发现自己与源域有直接血缘关系。**

这样主角同时身处四个势力的交叉点：
- 守夜局身份 = 掩护+任务来源
- 混脉特性 = 各势力都想拉拢
- 渊阁传承 = 真相线索
- 源域血缘 = 终极抉择

**这给MMO"同一角色多阵营任务线"和影视"主角的每一次选择都改变阵营关系"提供了天然结构。**

## 第四层 · 角色矩阵：可外延角色池

### 设计原则

影视宇宙需要每个重要角色都能开外传，MMO需要角色作为NPC/职业代表，ARPG需要NPC队友和Boss。

### 角色三层设计

每个重要角色都要具备：
1. **独立动机**（能脱离主角有自己的故事线）
2. **势力归属**（在五力矩阵中有位置）
3. **血脉方向**（能力可视化标签）
4. **视觉符号**（一个能被cos的程度）

### 建议的核心角色矩阵（示意）

| 角色原型 | 势力 | 血脉方向 | 功能 | 外延潜力 |
|---|---|---|---|---|
| 高智冷静主角 | 守夜局（明）/渊阁（暗） | 混脉 | 主视角 | 系列主线 |
| 暴力队友 | 守夜局 | 战脉 | 战斗+喜剧调节 | 外传电影/ARPG可操作角色 |
| 智囊队友 | 渊阁 | 灵脉 | 情报+解说 | 外传剧集 |
| 守护型队友 | 守夜局 | 御脉 | 防御+道德锚 | 外传 |
| 灰色对手 | 维序会 | 战脉/御脉 | 对手戏 | 反英雄外传 |
| 悲悯反派 | 归源教派 | 源脉 | 中期BOSS | 反派外传 |
| 神秘导师 | 渊阁 | 源脉 | 真相揭示 | 限定剧 |
| 终极存在 | 源域 | 原初 | 系列终局 | 无法开外传=留白 |

## 第六层 · 与你已有设定的契合度分析

### 你的偏好 vs 本设计的契合

| 你的偏好 | 本设计对应 |
|---|---|
| 高智冷静型主角 | 混脉+守夜局低阶身份=扮猪吃虎,情报分析驱动 |
| 血脉/传承型金手指 | 血脉品阶×觉醒阶段×登神悖论,金手指=混脉+深度收容不异化 |
| 收容异常世界观 | 折叠点机制+三层世界+收容即修炼,异常是核心而非背景 |
| 扮猪吃虎+探索真相 | 主角跨四势力身份,每层势力都是一层真相 |
| 参考《以神通之名》 | 血脉觉醒方向神通化,但用收容机制替代单纯吸收 |
| 参考《我在精神病院学斩神》 | 异常的不可名状感+收容的代价感,但更体系化 |
| 参考《穹顶之下》 | 表层世界的日常感+折叠点的"穹顶"概念,但更宏大 |

### 与300万字篇幅的匹配

- 三层世界 × 七阶觉醒 × 五势力博弈 = 至少21个大型剧情弧光的空间
- 每阶觉醒对应一个"大卷",每卷约40-50万字
- 收容异常的单元任务可以无限填充日常剧情
- 登神悖论作为终极悬念,300万字刚好走到神临的门槛

---

## 第七层 · 落地建议:小说创作时的改编埋点

### 写作时要主动埋的改编钩子

1. **每个异常都设计成"可被画出来的视觉奇观"**——影视特效和游戏Boss设计的基底
2. **每次血脉觉醒都伴随视觉变化**——发色/瞳色/纹路/光环,角色辨识度
3. **每个势力都有一个"入会仪式"**——影视名场面+游戏职业解锁动画
4. **重要战斗都发生在地标**——不要在无名荒野打,要在地标打
5. **每个重要角色第一次出场就给视觉符号**——一句话能描述的外形特征
6. **收容过程设计成"仪式感流程"**——不是简单击败,是有步骤的封印/收容,游戏机制天然
7. **留至少3个"未解之谜"贯穿全书**——影视季终悬念,游戏资料片预告
8. **每个势力都留一个"可洗白反派"**——外延空间

### 要避免的改编杀手

- 力量体系不要用模糊的"感悟"作为升级条件(游戏无法实现,影视无法呈现)
- 势力不要超过7个(玩家记不住,观众也记不住)
- 不要让主角的能力过于特殊化到无法归类(游戏无法做职业)
- 不要把终极真相写死(留白才有续作空间)
- 不要让任何势力完全邪恶或完全正义(灰色才有外延)
