# 全城恶人求我别接单

## 一、定位与核心卖点

- 品类：番茄小说网·男频·都市脑洞·系统流·情绪流爽文
- 一句话卖点：被"互殴判定"毁过一次人生的退役军人开网约车，绑定路见不平系统——这次，判定不是互殴。
- 情绪锚点：九寨沟事件（2026-11-02 老人打年轻人事件）引爆的全网情绪——"守规矩的人流血，闹事的人理直气壮"。每单元为读者泄一次这口气。
- 对标骨架：《模范出租车》（车厢聆听冤情→团队评估→乔装执行→代行复仇）×《铁拳教育》（单元案件+硬核惩戒+现实痛点）× 番茄系统文（点数兑换+雷达扫描）。
- 番茄风格标签：脑洞 / 系统 / 不憋屈 / 爽文 / 打脸 / 情绪流
- 改编远景：短剧/AI漫剧IP改编（对标《光杆司令》改编目标）。

## 二、主角人设

### 程义，30岁

- 退役武警机动支队侦察兵，服役期间维和立三等功。
- 人设前史·原点创伤：退役后一次见义勇为——地铁里制止猥亵，猥亵者反抗抓伤自己倒地碰瓷，程义被认定"互殴"拘留7天+赔偿4万。工作丢了，未婚妻走了，现在开网约车还债。
- 设计意图：武力有来源（退役兵）、憋屈有来源（被互殴判定毁过一次人生）、系统动机有锚点（我受过的冤，不想让别人再受）。
- 人设三反差：话少面善的司机 / 出手极稳的练家子；为陌生人拼命的热心肠 / 算账到小数点的冷静头脑；全网追猜的白车侠 / 自己坚决不认。
- 表现层：话少、点足、手稳；先固定证据再出手，动手前先做减法——"打得过吗/犯得着吗/赔得起吗"三问。
- 心理基线：冷峻为骨、爽感为皮。委屈时不动声色，看账单（系统对账单）时情绪释放。

## 三、金手指：路见不平系统

### 3.1 货币：正气值·四轨计分

| 行为 | 点数档位 | 设计意图 |
| --- | --- | --- |
| 出头（当面制止行凶/行恶） | 基础分 | 战斗爽点入口 |
| 出气（为受害者讨回公道、挽回损失） | 高额 | 单元案的清算收益 |
| 帮弱（不涉对抗的善意，免单送急诊、送迷路老人回家） | 小额稳定 | 日常刷分+人设温度，防主角只当战斗狂 |
| 打恶（实锤恶人被法律清算） | 按危害度×证据链完整度计倍率 | 证据链越干净倍率越高——"先取证再动手"从人设变成收益最优策略 |

独家倍率：

- 恃强凌弱加急费：受害者越弱、恶人越横，倍率越高。系统的价值观本身就是情绪流。
- 挺身者共鸣：现场有路人敢于作证/搭手，全员加成。把读者代入的围观者从"冷漠背景板"变成"潜在战友"。
- 倒扣红线：钓鱼执法、诱导犯罪、公报私仇——正气值倒扣+系统冻结。黑化防线，审核安全线。

### 3.2 系统人格：会计老哥

管正气值叫"绩效"，管兑换叫"报销"，管恶人叫"坏账"，清算完出《正气对账单》。冷峻题材的整活减压阀（番茄轻松不冷硬），暗扣全书"账"主题——恶人欠的账，总要还。

### 3.3 兑换商店·三轨

1. 技能轨（便宜，主力）：合法控制术（格斗不修仙）、法条即时检索+判例库、微表情识谎、话术施压、防御性驾驶。
2. 装备轨（中期）：车辆改装——记录仪阵列、行车数据云端实时公证存证（证据链倍率的硬件基础）、身体强化（轻微，战力封顶"顶级退役兵"，永不超自然化）。
3. 背景轨（贵，王牌）：背景编辑能力，见3.4。

### 3.4 背景卡：因果嫁接式背景编辑

- 能力名【背景卡】。消耗大量正气值，编辑一段与主角真实履历兼容的身份——编辑后，那个真实存在的组织里真的有你的档案，关键人物真的"记得"你。不是伪造证件（犯罪+审核双雷），是因果嫁接：系统在主角真实的"退役侦察兵"底档上生长枝蔓——你班长现在就在市局特勤队、你带的兵在跑媒体工作室……
- 独家爽点：把"你知不知道我是谁"这句恶人专属台词夺过来给主角用。恶人仗势压人的瞬间，主角淡淡亮牌反向碾压。
- 长线钩子：正气值终极用途不明。累计到天文数字时，系统弹出一张灰色卡【因果修正·一次】——让一件已烂尾的公共悲剧重来一次。中点重构的引信。

四条防崩坏规则：

1. 同时激活上限：Lv1只有1张，满级3张。每张都要花在刀刃上。
2. 规模阶梯定价：编辑"律所顾问"百万级正气值，"部委座谈嘉宾"千万级。后期通胀有出口。
3. 次数/有效期：卡用完即焚——靠山不能反复消费，防止每章无脑亮牌。
4. 兼容性约束：身份必须匹配年龄、履历、口音。编辑"京城世家公子"直接报错——世界的自洽就是审核的安全。

## 四、爽点循环（每单元5-10章）

1. 憋屈铺垫（血压拉满）：弱者被欺，围观冷漠，"和稀泥"式调解压受害者。
2. 委托入场（叮！）：车厢听取冤情，或系统雷达扫描同城求助帖。
3. 先礼后兵：主角指导取证（录音话术、时间戳公证）→ 当面对峙 → 对方仗势碾压。
4. 亮牌时刻：背景卡反打"你知不知道我是谁"，或武力线——系统实时提示防卫尺度，出手恰好在正当防卫线内。
5. 判定瞬间（本书独家爽点）：警察到场，证据链完整，这一次——不是互殴，是见义勇为。全网热搜玩梗。
6. 三重清算：法律拘留/赔偿 + 职场开除/行业禁入 + 社会性死亡。
7. 到账+埋钩：正气值入账，对账单整活，下一事件的影子露头。

情绪流的要害在第5步：读者被现实里"双方都有责任"的通报憋出的那口气，每单元泄一次。爽感不来自打得狠，来自判得对。

## 五、配角班底

- 会计老哥（系统）：吐槽役+账单梗。
- 老周（市局老刑警，引路人）：从奉命调查"白车侠"到暗中护航，中期收编博弈线——"你想当英雄，还是想想当编制？"（对标模范出租车的追查者+铁拳教育的制度内上位者。）
- 王大龙（车友群损友）：活宝兄弟+同城司机信息网络，喜剧调剂。
- 许晚（实习律师）：被程义救过的人。主角编辑的第二张高级背景卡恰好落在许晚所在律所，系统虚构的档案与真实人脉重合，虚实难辨。
- 暗线BOSS·戾值收割者：中期发现，恶人聚集处总有股力量在喂养戾气——有人以众人的戾气为食。主角收正气，对面收戾气，全书底层是城市情绪的对冲战争（情绪流升维成脑洞格局，中点第二增长曲线）。

## 六、开局·黄金三章

### 第1章《这次，不算互殴》

- 场景：虚构"云雾山景区"（九寨沟事件脱敏改编，人物全无原型）。
- 结构：排队冲突→老人暴打劝阻插队的年轻情侣→程义出手格挡反制→恶人儿子到场倒打一耙，"互殴"帽子即将扣下→【路见不平系统强制绑定】→当场整合行车记录仪+云端时间戳+多机位视频→恶人拘留，程义无责。
- 章尾钩子：正气值首充礼包。
- 要点：第1章就把九寨沟事件里那对情侣没等来的公道，先替读者出了。

### 第2章《深夜车厢》

- 系统规则展开（四轨计分+商店三轨），会计老哥人格亮相。
- 深夜单：醉酒姑娘吐露被上司性骚扰+拿把柄要挟，任务发布，证据链倍率教学。

### 第3章《先礼后兵》

- 程义接单，先教取证，再当面对峙，HR威胁反告诽谤→首张背景卡【媒体顾问】亮出，记者朋友"恰好"来做选题→恶上司社死+立案。
- 三章打满武力（1章）、系统（2章）、背景（3章）三条线，前30章不憋屈铁律执行到位。

## 七、前30章细纲

### 第一单元·景区公道（第1-7章）

- 第1章 这次，不算互殴：云雾山景区插队行凶案，系统绑定，铁证反杀，恶人拘留。首充礼包到账。
- 第2章 深夜车厢：系统规则教学，醉酒姑娘的职场性骚扰冤情，任务发布。
- 第3章 先礼后兵：取证教学，HR威胁反告，背景卡【媒体顾问】首亮，恶上司社死+立案。
- 第4章 余波与首单免三连：景区案后续（恶人家属诉讼威胁→媒体卡余威+平台处罚），帮弱轨初现（免单送急诊孕妇，小额正气值，账单整活）。王大龙登场（车友群吃瓜白车侠上热搜）。
- 第5章 碰瓷碰上了练家子：老太碰瓷程义（受害司机视角），反手取证套路演示，系统提示"自证陷阱"机制。
- 第6章 判定时刻：碰瓷案警方定责过程，程义"这位乘客，你戾气超载了"金句出圈，网上白车侠传说初起。老周远程注意到监控里的程义身影。
- 第7章 单元收束·第一张对账单：三案清算汇总，会计老哥出对账单整活；新钩子——深夜频道里有人发布"求助帖"，系统雷达响起。

### 第二单元·碰瓷产业链（第8-13章）

- 第8章 8点半的碰瓷联盟：职业碰瓷团伙碰瓷程义车友（王大龙被讹），团伙嚣张宣布"闹大就互殴"。车友群炸锅。
- 第9章 识谎术小成：兑换【微表情识谎】，卧底碰瓷群收集分工证据，把"互殴话术"倒打一耙成他们的新罪证。
- 第10章 碰瓷联盟覆灭战：收网，团伙头目"和稀泥"预判反被证据链倍率暴击，正气值首破万，解锁背景卡高级编辑功能。
- 第11章 背景卡·首次升级：次卡充值与代价展示（用完即焚），因果嫁接的惊喜——编辑出的"记者朋友"是真有其人，档案与真实人脉重合。
- 第12章 老周上门：老周借调查白车侠之名上门，猫鼠初次交手，程义滴水不漏。老周留下一句"这城市没有你，也转；有你，转得更干净点"。
- 第13章 单元收束：碰瓷团覆灭后续+系统提示"发现戾值异常聚集"（暗线伏笔第一次露头）。

### 第三单元·职业闭店人（第14-20章）

- 第14章 五年卡第二天就关门：乘客是"职业闭店人"受害者（健身房闭店跑路预付费坑人），委托入口。
- 第15章 追踪变更记录：跟踪法人变更线索，发现"职业背债人"灰产链条，取证教学（工商信息+涉诉记录穿透式核查）。
- 第16章 碰上钉子：闭店人背后有打手护场，程义武力首秀全开（正当防卫线内极限操作）。
- 第17章 第二张背景卡·律师顾问：背景卡【律师顾问】编辑，与许晚所在律所因果嫁接，专业法律火力全面介入。
- 第18章 背景卡的代价：编辑费用高昂+激活即倒计时，程义第一次意识到卡不是无限制王牌。
- 第19章 戾气反扑：闭店人背后金主收买水军全网黑程义"设局打人"，舆情战，程义用证据链+平台投诉双线反击。
- 第20章 闭店链覆灭：穿透式追责，全链条落网，正气值暴涨，系统弹出"戾值网络"概念图，暗线BOSS影子上桌。

### 第四单元·恶意差评师（第21-25章）

- 第21章 恶评轰炸：王大龙兄弟的奶茶店遭职业差评师轰炸（停车纠纷结怨），一晚半星差评几十条，近乎闭店。
- 第22章 骗局渗透：程义假扮受害商家暗访，450元刷30-40条差评的价目曝光，取证卧底模式升级。
- 第23章 平台之名：平台风控形同虚设，程义媒体卡二度亮牌，媒体曝光+平台强制介入双压。
- 第24章 威胁与反制：差评师头目线下威胁王大龙，程义系统提示防卫尺度，制服恶人，老周恰好"顺路"出现，首次公然默契。
- 第25章 疑云：差评师头目被捕后供述"有人付钱让我们盯上你"——暗线收割者第二次出手，戾值浓度检测可视化。

### 第五单元·街头老赖（第26-30章）

- 第26章 划车老赖全家桶：熊孩子划车+老赖家长全家倒地碰瓷，监控死角+人证反杀。
- 第27章 第二次"互殴"危机：老赖家族撒泼反咬，程义面临与第1章同样的"互殴"险境——但这次他有了系统、证据链和证人。
- 第28章 居民证言潮：单元核心情绪点——"挺身者共鸣"机制全开，整条街的邻居从冷漠围观到集体作证，读者代入围观者视角的爽点释放。
- 第29章 老赖覆灭：行政拘留+信用惩戒+社会性死亡，老周正式亮明身份邀请"喝茶"，收编博弈正式开题。
- 第30章 卷一收束·这城市欠的账才刚开头：五单元清算总对账，戾值网络可视化地图展开，系统提示【因果修正】功能解锁条件1/3。卷末钩子：同城热搜"白车侠是谁"高悬，程义关掉手机，接下一单。

## 八、卷级粗纲（粗纲法：每10-20万字一句话）

- 第1卷·街头公道（1-30万字）：系统绑定，20起街坊级善恶案，程义从落魄司机到全网热搜"白车侠"，攒出第一张高级背景卡。
- 第2卷·链条之下（30-60万字）：单元案背后挖出产业链（职业碰瓷团/黑中介/控评公关公司），解锁关系网编辑，老周深度登场，收编博弈开幕。
- 第3卷·和稀泥战争（60-90万字）：保护伞型反派——惯于各打五十大板的"调解高手"们，程义正面刚系统性不公，全网身份大猜想推至顶峰（主角永不主动揭底）。
- 第4卷·戾气暗流（90-120万字）：收割者浮出水面，情绪对冲战争展开，因果修正卡真相线索。
- 第5卷起：城市神话收束，"正气车队"开进更多城市（若数据达标可提前于90万字处引入车队编队玩法）。

## 十、案件池（20案·真实新闻锚点改编）
