## 一、ForgeTax 逆向设计文档

分析对象为 Unity IL2CPP 构建的发行包，代码经 Obfuz 混淆。采用 UnityPy 解析 `data.unity3d` 全量资源（46,150 个对象、2,407 个脚本类名、557 个 MonoBehaviour 序列化数据），并结合 `global-metadata.dat` 字符串扫描与场景分区、贴图、音频、动画命名交叉验证。

文档结构：概述与美术风格 / 世界观与叙事 / 核心玩法循环 / 14 个子系统详解 / 巢穴关卡分区 / 代码实现反推 / UI-UX / 证据附录。

每条结论标注了置信度：**实证**（资源中直接提取）、**推断**（多证据交叉）、**推测**（单一弱证据）。附录 D 明确列出未能还原的部分，主要原因是 IL2CPP 元数据版本 107 超出现有公开反编译工具支持范围，方法体逻辑无法还原。

## 二、炼器修炼手册

调研范围为《凡人修仙传》《修真世界》《百炼成仙》《一念永恒》《龙王传说》《修真四万年》六部作品，整理 17 项章节出处，并逐条标注证据级别（平台正文 / 公开节选 / 授权未核实的转载正文）。

手册核心主张：**炼器玩法不应停留在"把材料烧热、敲成一把剑"，而应落在"材料、术法与使用者之间的适配问题"上。**

- 工艺层：鉴材、控火、制坯、锻打、刻纹、定型、试器
- 修行层：法力、神识、技艺、传承共同决定能解决怎样的工艺问题
- 经营层：客户需求差异、弟子承担成熟工序、掌门攻克定制难题

含八段工序表、灵材与阵纹设计规则、失败与补救矩阵、六阶段修炼课程、三份从接单到验收的完整原创委托案例，以及宗门发展循环与玩法取舍建议。

文中严格区分三类内容：**【小说事实·S编号】**、**【设计归纳】**、**【原创建议】**。未核实完整规则的高阶器灵、器劫等仅作为扩展候选，不冒充原著设定。
