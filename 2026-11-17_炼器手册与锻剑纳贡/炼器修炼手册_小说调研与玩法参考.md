# 炼器修炼手册

## 东方玄幻炼器宗门经营游戏 · 小说调研与玩法参考

**适用设定：**玩家是神秘炼器宗师的弟子，开局接手没落的炼器宗门成为掌门，通过承接炼器委托、培养弟子与积累传承，逐步重振宗门。

**本手册的核心判断：炼器不只是“把材料烧热、敲成一把剑”，而是让灵材形成器形，让器形承载术法，再让器物适合具体使用者。**

建议把后续玩法拆成三层：

- **工艺层：**鉴材、控火、制坯、锻打、刻阵、定型与试器，让玩家亲手参与。
- **修行层：**法力、神识、技艺与传承共同决定能解决怎样的工艺问题，而不是只增加成功率。
- **经营层：**不同客户提出不同使用需求，弟子承担成熟工序，掌门攻克定制难题，订单收入反过来建设工坊与传承。

这里提供的是下一步设计的知识依据与候选方案，不是已经定稿的完整游戏系统；凡涉及材料参数、成长阶段、小游戏、宗门规则与委托案例，均为原创设计建议。

## 一、调研范围与证据使用方法

### 1.1 本次实际使用的样本

| 作品与作者 | 本次重点 | 对本项目的价值 |
|---|---|---|
| 《凡人修仙传》·忘语 | 金雷竹炼化、青竹蜂云剑成形、丹火与元神培炼 | 灵材特性、精细制器、神识负担与长期温养 |
| 《修真世界》·方想 | 震灵锄、寒磁铁加工、关联剑胚与符阵 | 最容易转译成可操作工艺与加工委托 |
| 《百炼成仙》·幻雨 | 地脉之火、炼器空间、九宫须臾剑加料后的性能变化 | 工坊建设、旧宝改良、材料与使用法诀的双门槛 |
| 《一念永恒》·耳根 | 念灵古法、试灵、多色火配方、永夜伞炼灵 | 旧器强化、炼火备料、秘方壁垒与风险判断 |
| 《斗罗大陆III龙王传说》·唐家三少 | 百锻与千锻、金属感知、师徒接单、协会检测 | 锤击手感、师承成长与工坊分工；属于玄幻补充样本 |
| 《修真四万年》·卧牛真人 | 废宝维修、法宝构件组装、定制红莲指虎 | 诊断维修、结构适配与客户定制；只借流程，不借科技外观 |

这六部作品不是同一个宇宙，也不是“炼器正统教科书”。本次采用具体章节中的可验证机制，没有全书逐章穷尽，不能据此判断某部作品“只有这些规则”。

### 1.2 三类内容必须分开

- **【小说事实·S编号】**：正文或公开节选实际支持的设定。编号可在第十五章找到作品、章名、页面和链接。
- **【设计归纳】**：从不同文本中提炼出的共同问题，例如“先了解用途，再选择工艺”。它是研究结论，不是所有小说的统一规则。
- **【原创建议】**：为本项目构造的操作、数值、材料、流程、课程和委托。可以使用、修改或放弃，不能倒过来声称是小说原设。

证据强度另行区分：平台正文、平台公开节选、授权未核实的转载正文、二手整理。**站点域名像正版平台，不代表资源站问答就是作者原设；标题检索成功，也不等于读到了该章正文。**

### 1.3 三条不可混用的边界

1. **炼器、炼灵、祭炼不是同一业务。**炼器制造或加工器物；《一念永恒》的炼灵可强化已有物品；祭炼、温养多涉及持有者对既有法宝的培炼与掌控。
2. **“品阶”至少有四种对象。**材料品阶、器物品阶、炼器师职业等级、修士境界不能自动互换。用高阶晶石激活农具，不意味着农具立刻成为高阶法宝。
3. **专名与特殊能力不能直接搬进原创世界。**青竹蜂云剑、永夜伞、蓝色星海等用于定位案例；本项目应自行命名与定义规则，不移植主角独有外挂、原作秘术或剧情。

## 二、六部小说的炼器机制拆解

### 2.1 《凡人修仙传》：先处理灵材，再精细成器

**案例一：金雷竹的炼化。**【小说事实·S01】第四百一十三章《炼化》写到，竹材表面的淡金电弧阻挡丹火，电弧消失后才进入熔化、去杂与分料阶段；处理后的液料被分成十二份。这说明特殊材料并不只是一根“进度条”，其内在灵性会改变工艺阶段。

**可借鉴之处：**让材料呈现可观察的变化，再要求玩家作判断。雷弧是否消退、杂质是否析出，应该对应工艺状态；不能只是炫目的背景特效。

**案例二：七十二剑坯与逐剑刻阵。**【小说事实·S02】第四百一十四章《成形》涉及液态剑坯塑形、融入精血及辅料、逐柄细炼，并参照金页图示刻入微型阵式。同步控制大量剑坯给神识带来负担。这是制造过程中的特殊实例，七十二柄不是通用批量上限，加入精血也不能自动归类为成品认主。

**可借鉴之处：**批量制作不是无限并行。先批量制坯，再逐件做精细刻阵，可以给“掌门亲手做关键工序、弟子负责准备”的分工提供依据。

**案例三：成器与温养分开。**【小说事实·S03】第三百九十八章《结丹与法宝》涉及结丹后以丹火制作、修整法宝，以及通过丹火和元神培炼增强法宝威能。

**可借鉴之处：**交货不必意味着器物故事结束。客户使用一段时间后带回调校，宗门可以观察器物长期成长。但温养不会凭空多出一件库存，也不能把客户多年修行写成掌门几分钟的制造工时。

**不应照搬：**必须结丹才允许玩家开始一切炼器、一次操作同时造七十二把、主角专有神通自动转换为普通商品属性。

### 2.2 《修真世界》：器形、材料与符阵要协同

**案例一：震灵锄。**【小说事实·S04】第九章《炼器》中，青铜被锤制成锄形，刻入基础阵式“震”，嵌晶石激活，再以炎铁矿熔液加固、装柄。青铜易塑形，但变形可能危及阵式。章中也说明这类农具连一品都入不了；这不是一次完整的完工评级仪式。

**可借鉴之处：**最好的新手委托不一定是飞剑。灵田农具也能展示“物理结构＋灵力功能”，并与宗门民生收入衔接。高阶能源不应越过结构与功能限制，自动把低阶农具升级。

**案例二：寒磁铁半成品加工。**【小说事实·S05】第一百零六节《半成品加工狂人》中，委托要求将寒磁铁分为四块，左莫先探查磁性分布，普通飞剑切割会损害材料性质；他通常不接四品炼化，因为毁料赔偿过重。本节未完整展示最终切割结果。

**可借鉴之处：**委托目标可以是“保住材料特性”，而不是“输出更高伤害”。鉴材、切线、报价、拒单和赔偿，本身就能形成经营玩法。

**案例三：相互关联的剑胚符阵。**【小说事实·S06】第一百六十一节《炼制剑胚》中，寒磁铁经过除杂、熔化与塑形；四件器胚各要刻一种不同的四品符阵，阵式彼此关联。凝结阶段开始刻阵，火力不足时加强火焰，施诀过程有明显负担。正文展示了一枚剑坯的制作，不能据此确认整套已经全部成功。

**可借鉴之处：**成套器物的难点不是把同一件复制四遍，而是部件之间的匹配。不同部件可以共享器图，也有各自工序与验收。

**不应照搬：**数字品阶与其他作品的法宝等级硬换算、把“刻阵”一律安排在完全冷却以后、把外部阵法与器物内部阵纹当成一个制作对象。

### 2.3 《百炼成仙》：设备条件、改良材料与操控法诀

**案例一：先建炼器空间。**【小说事实·S07】第四百八十章《炼宝》的平台公开预览说明，林轩扩建炼器空间、引入精纯地脉之火，然后开始法宝淬炼。预览不足以还原完整流程，也不足以判定每一步究竟是新造还是重炼。

**可借鉴之处：**宗门升级可以改善真实工艺条件，而不是只写“成功率＋5%”。修复地火通道后能处理以前无法加工的材料，收益来自新增业务。

**案例二：九宫须臾剑改良。**【小说事实·S08】第两千七百七十四章《九宫须臾剑的意外收获》中，加入域外天金与幻阴魔花后，剑体的厚薄、重量、韧性和锋锐发生变化；“剑灵化虚”效果还受天金数量、纯度以及使用法诀影响。该章主要展示改良后的性能，不是完整重炼说明书。

**可借鉴之处：**旧宝改良能改变器物的使用方式，不必只增加攻击力。更轻、更稳、更加省力，均可成为订单价值；材料升级与客户是否掌握相应法诀应分开。

**不应照搬：**把蓝色星海解释成“能修复任何残宝”，或把剑灵化虚造成的变化写成通用补剑工艺。

### 2.4 《一念永恒》：旧器强化、多色火与秘方

**案例一：试灵与成败表现。**【小说事实·S09】第八十一章《念灵古法》中，飞剑注入灵力后显现银纹，另有裂缝、废品的表现；白小纯还通过补加工与替剑改变张大胖对炼灵成败的认知。因此，不能把此段写成“张大胖连续自行炼灵成功”的证明。

**可借鉴之处：**强化结果需要可见的验证，而不只弹一个成功框。也要区分“器物真实状态”与“角色对成功的信念”；本项目更适合把前者作为交货验收，后者用于人物剧情，避免给玩家不透明的隐藏心态惩罚。

**案例二：火焰配方并不唯一。**【小说事实·S10】第五百六十六章《炼魂，就是炼灵！》的公开节选涉及炼魂师自行炼制多色火；一至十四色有历代积累的多套配方，高色秘方存在家族间的知识壁垒。

**可借鉴之处：**器谱与火谱能成为宗门的生产资产。同一种工艺目标有不同成本和原料路线，有利于供应商变化、秘境材料与师承交换。但多色火的颜色数不是仙器品阶。

**案例三：备火与炼灵是两段工作。**【小说事实·S11】第六百三十七章《全身是宝……》的公开节选写到，白小纯利用魂材炼出十四色火，再对永夜伞进行炼灵，器物外形有所变化。

**可借鉴之处：**把“准备特殊火源”和“处理订单器物”拆成不同工位，培养弟子协作。魂材属于该作品的特定世界设定；原创项目可以换成天地火种、灵息结晶等非人物魂魄资源。

**不应照搬：**把多色火、炼灵次数与物品等级合并成同一数值；把特殊锅具的效果直接做成无限无风险强化。

### 2.5 《龙王传说》：锤击不是次数，而是对金属的理解

**案例一：百锻、千锻与材性判断。**【小说事实·S12】第十三章《千锻钨钢锤》中，通过反震和材料变化辨识纹理与特性；反复锤击减少杂质，材料需要承受更高强度锻造。原文虽然涉及锤击次数，但不能把它简化为游戏中的“点够一千次必定升级”。

**可借鉴之处：**声音、落点、形变与反震应给玩家同一工艺状态的不同线索。真正熟练的玩家是在调整锤法，而不是机械增加点击量。

**案例二：师徒工坊分工。**【小说事实·S12】邙天承接部件加工，困难任务亲自处理，简单任务交给弟子；安排专门学习日，收入与工作数量、品质有关。

**可借鉴之处：**培养弟子不是增加一个自动产出槽。掌门教会成熟工艺后，弟子能接走常规任务；掌门的时间由重复劳动释放出来，用于高价值研发。

**案例三：职业追求与能力瓶颈。**【小说事实·S13、S14】第五十八章《创造生命》涉及职业徽章及七、八级圣匠称谓，并提出真正锻造的生命观念；第七十一章《练锤》说明高阶锻造越来越依赖悟性与魂力，先天力量不能包办全部问题。该章还展示协会检测、交付报酬、使用师傅工坊的回报安排。

**可借鉴之处：**技能、修行与职业认可是不同成长线；“替师门制作一件合格器物”可比缴纳抽象学费更有师承感。

**核验边界：**本次未取得足以完整核实灵锻、魂锻、天锻操作及失败细则的正文，不把二手文章中的百分比、雷劫次数或职业表当作已核实资料。斗罗的魂力与武魂体系也不直接移植为本项目修仙境界。

### 2.6 《修真四万年》：维修、组装与真正制造的区别

**案例一：废宝诊断与功能复用。**【小说事实·S15】第一章《法宝坟墓》中，李耀修好拾获的狩猎手表，将振动识别功能用于监测垃圾船，并判断废旧器物的回收价值。

**可借鉴之处：**残损器物可以修复、拆材或转作其他用途。原创玄幻世界可表现为旧灵盘、寻踪铃与阵眼，不需要电子屏幕、机甲或现代垃圾场外观。

**案例二：组装不等于炼器。**【小说事实·S16】第五十四章《三件大杀器》中，筛选和拼合预制构件不算真正炼器，但仍涉及稳固连接、装配准确与结构改动。

**可借鉴之处：**宗门可以经营标准部件装配和新器研发两种业务；组装成熟构件适合弟子练习，原创器图的试制需要掌门负责。

**案例三：为具体使用者定制。**【小说事实·S17】第三百章《法宝博览会》相关介绍段涉及红莲指虎：围绕丁铃铛的战斗习惯，以材料与攻击符阵配合制造，并通过试用呈现功能。详细内容本次来自授权未核实的转载正文，因此证据低于平台正文。

**可借鉴之处：**问清客户的功法、使用姿态与预算，比盲目做最高品阶更重要。客户试器可以成为交货高潮。

**不应照搬：**现代军工批量生产外观、跨世界通用职业等级、小说特殊材料直接成为原创项目的必需配方。

## 三、炼器基础术语与器物分类

### 3.1 常用术语工作表

以下解释是便于游戏团队沟通的工作定义，不宣称每部作品完全同义。

| 术语 | 工作定义 | 设计时应区分的对象 |
|---|---|---|
| 灵材 | 具有特定灵性或可承载灵力的材料 | 原料、经过加工的精料、成品部件 |
| 器胚／器坯 | 尚未完成全部功能的器物雏形 | 能否返工、是否已锁定形状与材质 |
| 器胎 | 可被定义为器物核心载体 | 有的作品与器胚近义，不宜无故增加独立工序 |
| 熔炼 | 对材料进行熔化、融合或分离的加工 | 金属可熔炼，不等于所有木、玉、骨料都要熔化 |
| 淬炼 | 提纯、加固、反复加工的广义说法 | 不一定等于一次浸水冷却 |
| 淬火 | 特定定型或冷却阶段 | 小说中的用法不一，应以本项目器图定义 |
| 控火 | 调整火力、范围、持续与火性 | 火焰种类与操控精度分开 |
| 符纹／阵纹 | 器物上承载术法关系的纹路 | 单个纹式、完整阵路、工坊外部阵法 |
| 器图 | 器物结构与工艺依据 | 外形图、材料说明、阵纹图、工序说明 |
| 法诀 | 操控或实施工艺的方法 | 制作者法诀与客户使用法诀 |
| 神识／神念 | 感知与精细操控的能力 | 识别精度、操作范围、并行负担 |
| 灵力／法力 | 工艺与器物运转所需的能量 | 制造时供能、使用时供能、储备容量 |
| 启灵 | 为项目定义的灵性激活过程 | 不应自动等于获得人格化器灵 |
| 器灵 | 若世界观允许，器物中的灵性主体 | 原生器灵、培育器灵、外来灵性必须分开 |
| 祭炼 | 持有者使器物与自身建立或深化联系 | 通常不是从原材料制造新器 |
| 温养／蕴养 | 持续培炼或培育器物 | 时间、条件、使用历史与维护 |
| 认主 | 明确操控权或建立契约关系 | 是否绑定、能否转让、修理权限 |
| 本命法宝 | 与修士形成特殊长期联系的法宝 | 各作品的数量、条件、损毁后果不同 |
| 炼灵 | 《一念永恒》中与既有物品强化相关的特定体系 | 不直接当作所有作品的“炼器升级” |
| 器劫 | 原创世界可采用的高阶成器考验 | 本次没有核实统一原著规则，先作扩展候选 |

### 3.2 器物不是只有兵器

【设计归纳＋原创建议】宗门的客户面应从日常生活逐步扩大，避免“所有人都来买剑”。

| 器物方向 | 候选产品 | 主要验收目标 |
|---|---|---|
| 民生与灵田 | 震土锄、引水盘、温棚灯 | 工作效率、节能、持续稳定 |
| 修行辅助 | 聚息蒲团、护脉佩、静心铃 | 适配功法、灵力流量与安全 |
| 防护与出行 | 护身玉佩、轻身履、避雨斗笠 | 防护类型、负担、环境适应 |
| 战斗兵器 | 飞剑、长枪、法盾、法印 | 武技适配、锋韧、操控与耐久 |
| 宗门工程 | 阵旗、阵眼、地火阀、灵材储柜 | 连接稳定、可维修与批量一致性 |
| 生产工具 | 炼器锤、刻纹笔、试灵盘、炉胆 | 工艺能力、精度与可重复性 |
| 特殊器物 | 古器修复、伴生器、成长器 | 历史保留、灵性稳定与契约条件 |

空间宝物、完整傀儡和大型飞舟有较大的规则与制作成本。可列为远期器类，不必成为初版必需业务。

### 3.3 器物评价应拆成三个维度

【原创建议】不急于制定“凡器—灵器—宝器—道器—仙器”的长阶梯。先定义三个独立维度：

- **能力层级：**能承载什么功能，例如单一术法、复合阵式、持续成长、独立灵性。
- **成品品质：**在同一能力层级内，制造是否稳定、是否有瑕疵、是否耐用。
- **客户适配：**同一件器物对不同功法、修为、使用习惯是否合适。

一枚制作精良的低耗护身佩，可能比高阶但客户根本无法催动的法盾更符合订单。最高等级不能代替合格验收。

## 四、炼器师的修行与能力结构

### 4.1 五项能力，不是一个成功率

【设计归纳】《凡人》的神识负担、《修真世界》的施诀与刻阵、《龙王传说》的魂力与悟性，均可支持把能力拆开思考。【原创建议】本项目可先采用下面的工作模型。

| 能力 | 能解决的问题 | 成长后的实际变化 |
|---|---|---|
| 鉴材与理解 | 辨认灵性、缺陷、用途和材料兼容 | 看得见更细的材纹、能识别混料与隐伤 |
| 控火与供能 | 材料加工、稳定炼制、应对火势变化 | 多区火候、持续供能、处理特殊火性 |
| 制器与锻打 | 器形、结构、强韧和部件匹配 | 更少无效锤击、更复杂器形、可控返工 |
| 神识与刻阵 | 微型纹路、精细施诀与并行操作 | 阵纹更精密、更多关联部件、诊断更准确 |
| 试器与调校 | 使用者适配、故障定位、交货判断 | 能判断“造得好但不适合”的问题 |

修为可影响持续供能与操控上限，技艺决定如何正确使用这些能力。宗师弟子的身份可以解释优秀基础和特殊视角，但不应等于开局无所不能。

### 4.2 神秘宗师的传承该给什么

【原创建议】优先赋予主角“可验证的工艺优势”，而不是直接送一座无限资源炉。

- **识缺：**能看到器物灵路不顺的症状，仍需玩家判断原因。
- **补缺：**拥有一种旧器修复或阵纹转接方法，擅长别人不愿接的残损委托。
- **辨谱：**读懂残缺器图中的工艺线索，但需要试制证明推断。
- **传艺：**掌门验证过的工序可以整理成宗门讲义，转化为弟子能力。

不要同时把四种优势全部作为开局外挂。可选一种主特长、另一种作为传承成长方向。

### 4.3 成长的关键是“新增问题”，不是“旧问题乘十倍”

- 初期会稳定做一件器物。
- 中期会应对不同批次材料，并为客户修改器图。
- 进阶会制作关联器组、诊断高阶旧器、组织弟子协作。
- 宗师阶段会在材料、功能、风险与客户约束之间创造新解。

不建议让玩家每提高一阶，就把同一个锤击小游戏做更长时间。

## 五、灵材认识、搭配与鉴定

### 5.1 每份灵材至少回答六个问题

【原创建议】材料条目采用“灵性＋工艺性＋状态”描述。

1. **性质是什么？**金、木、水、火、土等只是初始标签，还可有雷、风、镇定、储灵等独立性质。
2. **做什么合适？**承力、导灵、储灵、隔灵、稳定或生长；不是所有材料都该用来提高攻击。
3. **怎么加工？**熔炼、锻打、雕刻、切割、浸润或保留天然结构。
4. **怕什么？**过火、急冷、冲撞、某种火性、错误切线或灵性冲突。
5. **这一批质量如何？**纯度、内裂、受潮、耗灵、旧阵残留与来源可信度。
6. **能替代什么？**换材料后哪些功能不变，哪些成本、风险或外观必须改变。

金雷竹电弧阻火、寒磁铁加工保磁说明，灵性不是一串毫无工艺影响的属性文字。【小说事实·S01、S05】

### 5.2 原创材料范例库

下表名称、功用与限制全部为**原创示例**，不是任何小说的官方材料表；无固定真实熔点，不用于现实金属加工指导。

| 材料 | 主要用途 | 工艺选择 | 典型限制 |
|---|---|---|---|
| 青纹铁 | 承力器骨、农具主体 | 锻打、局部加热 | 材纹断裂会降低长期可靠性 |
| 赤纹铜 | 温热、传火类部件 | 熔炼、铸形 | 不适合直接作为高韧承力骨 |
| 引灵银 | 灵力通路与细纹连接 | 少量融合、刻纹填料 | 过量不等于更强，可能超出器胚承载 |
| 澄灵砂 | 辅助排杂、稳定加工 | 分批加入 | 错误火性下可能带走有用灵性 |
| 云纹石 | 轻身类部件、风性载体 | 顺纹切割、镶嵌 | 碎成粉末会失去结构优势 |
| 藏火晶 | 缓冲或储存火性灵力 | 独立阵眼、温和调校 | 超过储量出现裂纹和泄灵 |
| 清露玉 | 冷却与水性稳定 | 雕刻、浸润 | 急冷可能破坏天然纹路 |
| 息声木 | 减小器物与工坊噪声 | 保纹雕刻 | 全部熔化会毁掉所需特性 |
| 回元墨 | 连接、修补阵纹 | 笔刻、填隙 | 不能替代已经断裂的承力结构 |
| 归纹丝 | 连接软硬部件 | 缠结、固定、封纹 | 张力与导灵方向需要匹配 |
| 霜纹角 | 耐寒防护部件 | 分段切割、嵌合 | 外层完好不代表内部无裂 |
| 青灯火种 | 稳定的小型炼器火源 | 配合炉阵培育与使用 | 特长是稳定，不是最高温或万能火 |

### 5.3 配料不是“越稀有越好”

【原创建议】将配方材料按功能分为：主材、辅材、阵眼、纹路材料、工艺耗材。每一种加入都要回答其作用。

以护身佩为例：玉材承载器形，少量导灵材料连接灵路，阵眼承担储灵，稳定材料控制漏灵。给它加入大量锋锐材料不会自然提高护身性能，反而可能提高耗灵与加工难度。

至少允许三类有意义的替代：

- 便宜但需要更多加工的主材。
- 昂贵但更稳定、节省神识的辅材。
- 能完成核心功能，但要牺牲某项附加功能的备选材料。

材料替代若会改变委托约定，应先重新报价或取得客户确认。

### 5.4 五行相生相克如何落到操作

【原创建议】五行可作兼容关系的表达方法，不要只做五种颜色。

- **相生：**允许一类材料帮助另一类稳定供能或保留特性。
- **相克：**意味着直接接触可能损耗，但不等于绝对不能共存。
- **隔离：**用器形、阵眼或分层结构让冲突材料不直接接触。
- **转接：**增加已掌握的稳定纹式，使两类材料能够协同。

例如水性玉与火性晶可以放在器物的不同部位，通过隔离纹连接；这样获得复合功能，也增加工序和承载成本。这里只是原创机制范例，不是“所有小说的五行炼器公式”。

## 六、从接单到交货的炼器工序

### 6.1 建议的八段工作链

【设计归纳＋原创建议】先用八段链组织资料，再按器类删减工序。**不要求每个订单每次都做八个小游戏。**

**问器 → 鉴材 → 定谱 → 炼材 → 制坯 → 布纹 → 定型／启灵 → 试器交付**

| 阶段 | 玩家主要判断 | 操作载体 | 可见反馈 | 失败后的主要去向 |
|---|---|---|---|---|
| 问器 | 客户真正需求、预算与期限 | 对话、委托簿 | 用途与验收条件明确 | 改方案、补问或拒单 |
| 鉴材 | 材性、隐伤、库存与风险 | 鉴材台、神识探查 | 材纹、灵性、裂隙 | 分选、换料、降档 |
| 定谱 | 选器形、工艺路线、功能优先级 | 器图、材料格、阵纹拓本 | 方案可行性、风险提示 | 修改器图与报价 |
| 炼材 | 火性、去杂、配料时机 | 灵炉、火诀、钳具 | 杂质析出、灵性变化 | 停火、分料、返炼 |
| 制坯 | 结构、落点、力度与天然纹路 | 砧台、模具、雕刻台 | 器形、锤音、形变 | 局部返工、换工法 |
| 布纹 | 阵路、阵眼、供能与承载 | 刻纹笔、神识、器胚 | 纹路连通、堵点、泄灵 | 抹纹重刻、封纹 |
| 定型／启灵 | 何时收束、是否激活灵性 | 冷却台、定型诀、养灵位 | 成器稳定、器鸣、灵性反应 | 降低目标、改为普通器 |
| 试器交付 | 是否合格、是否适配 | 试灵台、客户试用 | 功能、负担、缺陷清单 | 调校、返修、重新协商 |

### 6.2 问器：把故事变成工艺约束

【原创建议】不要只让客户说“我要一把上品剑”。至少问明：

- 用于赶路、防御、灵田还是战斗？
- 客户能持续提供多少灵力，使用多久？
- 更在意轻、快、稳、省力还是爆发？
- 原料由谁提供，能否替代？
- 是否必须保留旧器身份、家传纹路或契约？
- 最迟交货时间、验收方法和失败责任是什么？

同一器图可因答案不同而产生真正不同的做法，这比随机增加伤害词条更适合掌门经营。

### 6.3 炼材：去掉杂质，不要去掉价值

【设计归纳】“提纯”与“保留目标灵性”必须同时考虑。【原创建议】把去杂分为可见杂质、隐性冲突和材料本来就有的灵性结构。

- 普通矿料：让玩家学会观察杂质析出，确定收料时机。
- 天然灵材：先判断是否允许熔化，必要时只加工外层。
- 双材融合：按先后顺序处理，使辅材承担明确功能。
- 旧器回炉：先评估保留部分，不能把全部历史与灵性一键抹掉。

高阶材料不应只延长加热时间，应要求不同判断，例如保住材纹、隔离冲突或先处理阻火灵性。

### 6.4 制坯：锻打、铸形与雕刻并存

【原创建议】如果全游戏只做敲剑，器类变化很难真正成立。

- **锻打：**金属器骨、农具、剑坯；重点是落点、力度与结构稳定。
- **铸形：**法印、炉胆、规则部件；重点是成形一致性与材料融合。
- **雕刻：**玉佩、灵盘、木器；重点是顺纹、保留灵性与细部空间。
- **组装：**阵旗、法盾、组合器；重点是部件适配与连接可靠。

一款小体量游戏可以先只实现锻打与刻纹，其他工艺暂用简化操作，不必开局同时完成四套系统。

### 6.5 布纹：可以在不同窗口完成

【小说事实·S02、S06】正文中刻阵与细炼、凝结窗口有关，不是一条统一的“完全冷却后再刻图”规则。

【原创建议】器图应写明纹式完成时机：热态神识刻阵、冷态实物刻纹、装配后连纹三种工法可分阶段开放。相同功能因工法不同，操作窗口和返工余地也不同。

### 6.6 试器：让成品证明自己

【原创建议】每一器类至少有一种非文字验收：

- 飞剑：低耗悬停、转向稳定、回收准确。
- 护身佩：承受指定冲击、显现护罩、记录漏灵。
- 灵锄：翻动目标土壤，比较耗灵与连续工作效果。
- 阵旗：与其他旗同步激活，观察连接一致性。
- 修复旧器：先恢复原有核心功能，再测试新增改良。

客户试用时的反馈应能回指工艺：不是一句“品质不够”，而是“转向时灵路断续”“一击很强但无法持续使用”。

## 七、灵火、火候与炼器工坊

### 7.1 火焰等级与火候精度分开

【设计归纳】地脉之火是设施条件，多色火是特定作品的炼火体系，丹火与修士能力有关。不能排成一张所有小说通用的彩虹火榜。

【原创建议】为火源定义四项：

- **火性：**适合哪些材料，排斥哪些灵性。
- **加工能力：**能否处理当前材料，不必显示现实摄氏温度。
- **稳定性：**波动大小，工坊能否持续维持。
- **可控性：**能否细分火区、局部加热、快速收束。

一团强大但难控制的火，不一定比稳定的小火更适合细纹玉器。

### 7.2 控火的三种候选操作

全部为**原创候选**，不必同时实现。

| 路线 | 主要操作 | 玄幻表现 | 主要风险 |
|---|---|---|---|
| 窗口控火 | 根据材料状态调节火力与收料 | 材纹亮暗、炉火收放、杂气逸出 | 长时间盯同一条进度条 |
| 分区御火 | 分别照料器胚不同部位 | 神识牵引多股火线 | 信息过多、操作负担过重 |
| 火诀组合 | 选择合适火诀、投料与处理顺序 | 炉阵响应、火种变性 | 退化成背固定按键答案 |

初版可用窗口控火，配一种特殊材料变化；中期再加分区。无论哪种，都要允许玩家提前观察风险、停止或改道。

### 7.3 工坊设施的意义

| 设施 | 解决的工艺问题 | 不宜只给的抽象奖励 |
|---|---|---|
| 地火室 | 持续供能、处理特定矿料 | 单纯提高所有订单成功率 |
| 灵炉／炉胆 | 容纳加工范围、隔离材料冲突 | 只有金币价值与外形更大 |
| 鉴材台 | 分析批次、旧器隐伤、保材加工 | 自动把一切未知直接变已知 |
| 砧台与锻锤 | 结构稳定、局部加工、操作反馈 | 自动跳过所有工艺判断 |
| 刻纹台 | 精细定位、阵纹模板、修补灵路 | 不限数量堆叠术法 |
| 试灵台 | 给出功能诊断与客户适配数据 | 永远显示一个总评分 |
| 养器位 | 特定器物温养、稳定灵性 | 无条件免费长期加属性 |
| 藏谱阁 | 整理器图、失败记录与讲义 | 只有解锁列表，没有知识作用 |

### 7.4 持续炉火与掌门精力

【原创建议】神识与法力在不可中断工序中形成压力，在日常经营中则要可管理。不要让玩家必须实时守炉数小时。

- 已学会的常规炼材由弟子维持。
- 掌门进入关键窗口时亲自操作。
- 接单前展示所需供能与可用休整窗口。
- 持续生产以经营回合表示，玩家动作以短时交互表示，两者不强制等比例。

## 八、阵纹、器图与功能设计

### 8.1 器形是载体，阵纹是功能，不能彼此替代

【小说事实·S04、S06】震灵锄把基础阵式放进具体器形，关联剑胚又要求不同符阵配合。【原创建议】阵纹设计需回答四个问题：

1. 灵力从哪里进入？
2. 经过哪里、会损失多少？
3. 在哪里形成效果？
4. 效果收束后是否回流、散掉或储存？

不必采用电子电路外观。器胚上的山川纹、篆纹、云纹可承载同样明确的连通逻辑。

### 8.2 基础纹式候选

下表是原创功能词汇，不是原作阵纹目录。

| 纹式角色 | 候选名称 | 玩家应理解的功能 |
|---|---|---|
| 输入 | 引灵纹 | 接受外部灵力 |
| 汇聚 | 聚息纹 | 将供能集中到指定部位 |
| 通路 | 通灵纹 | 连接阵眼与效果区 |
| 缓冲 | 藏灵纹 | 暂存灵力，减轻瞬间负担 |
| 稳定 | 镇纹 | 减少失控与冲突 |
| 输出 | 锋纹／护纹／轻身纹 | 将灵力转化为用途 |
| 收束 | 回流纹 | 将残余灵力引回或有序散去 |
| 隔离 | 隔灵纹 | 避免冲突材料直接互扰 |

最初只开放输入、通路与一种输出；掌门掌握新功能后，更多纹式才形成选择。

### 8.3 “多一个功能”必须付出代价

【原创数值示例】用简单承载单位验证方案，不表示小说原有数值。本例只演示可选功能预算：输入、基本通路和阵眼占位已纳入器胚基础结构并预先扣除，下面的80是剩余可分配上限。

- 玉佩器胚剩余的功能承载预算为80。
- 聚息纹占用20，护身纹占用50，回流纹占用15，合计85，超出预算。这是定谱时应修改的草案，不能作为合格方案直接开工。
- 方案一：将护身目标降低，占用减至45，合计80。
- 方案二：换用承载更好的器胚，但成本与工时上升。
- 方案三：先不做回流附加功能，合计70，接受更高使用损耗，并向客户说明。

承载预算与运行耗灵是两个指标，不应将“占用80”当成“每次消耗80法力”。第十章的超载失稳是强行激活越界器物的故障示例，不是合法的交货状态。初版可以只做一个约束，避免同时塞入太多隐藏变量。

### 8.4 器图的四层资料

【原创建议】每张器图包含：

- **结构层：**器形、受力骨、阵眼位置与可用刻纹区。
- **材料层：**主材功能、可替代辅材、不能混用的材料。
- **工艺层：**处理顺序、关键窗口与返工截止点。
- **功能层：**效果、耗灵、客户适配与验收方法。

发现一张残图不等于获得万能配方。可以只先看懂结构，试制后补齐材料与工艺说明。

### 8.5 成套器物与协作

【原创建议】飞剑组、阵旗组与工坊阀组应有“单件合格”和“成套匹配”两层验收。掌门安排弟子制作单件，最后亲自校对关联纹路与统一目标。

协作增加的是可管理的复杂度，不是单纯在计时条上并行十个订单。不同弟子可以擅长不同工序，不必每个人都独立制造完整法宝。

## 九、启灵、器灵、认主与温养

### 9.1 四种概念分别设计

【原创建议】先把规则拆开：

| 环节 | 解决的问题 | 不意味着什么 |
|---|---|---|
| 功能激活 | 器物开始按阵纹运转 | 不意味着具有人格 |
| 启灵 | 建立项目定义的灵性反馈或成长能力 | 不意味着必然诞生器灵 |
| 器灵培育 | 器物中形成可互动的灵性主体 | 不意味着自动服从持有者 |
| 认主与契约 | 操控权、约定与使用联系 | 不意味着可以随意重炼或转让 |

炼器师可能是制造者，客户才是未来持有者。交货用的法宝不应默认绑定掌门本人。

### 9.2 器灵的三条原创路线

本次正文证据不足以建立通用“器灵生成法”，以下只作为世界观候选。

- **内生路线：**长期使用与温养，使器物积累灵性；适合成长器和老客户回访。
- **灵种路线：**安置天地孕育的灵种，通过正确器形与环境培育；适合经营稀有资源和养器位。
- **修复路线：**器物原有灵性受损，掌门诊断并恢复联系；适合宗师弟子的独特专长。

不要求器灵全部拟人化。器鸣、纹路趋向、对某种工法的亲近或排斥，就能构成早期反馈。人物魂魄拘禁或大量献祭并非本项目炼器核心所必需。

### 9.3 温养的条件与服务

【小说事实·S03】持有者培炼法宝与制造完工不同。【原创建议】宗门可提供三种后续服务：

- 建立适合客户的温养方法说明。
- 将不稳定新器放在养器位暂时调校。
- 收集客户使用反馈，安排升级、修复或换料。

不采用“等待十天就自动升一级”的唯一规则。温养应与器物用途、条件或使用历史有关，且不要求玩家现实挂机。

### 9.4 本命器与普通订单的区别

【原创建议】本命器是特殊定制业务，不是所有器物都自动本命化。客户应参与适配确认，制作前明确风险、绑定与转让规则。

可以用“本命器”承载长期人物故事，但先避免把损毁必死、失控必然夺舍等极端规则设为默认。不同小说的本命法宝条件并不统一，本项目需自行定稿。

### 9.5 器劫作为远期高潮

【原创候选，未作为已核实小说机制】若后续选择“高阶器物引动天地考验”的路线，应先明确它考验什么：器物结构、灵性稳定、工坊防护还是掌门临场判断。

可用护宗阵减轻冲击、引劫纹分散压力、主动降格保器形成决策。但这些是原创方案，不声称来自本次未取得完整正文的天锻体系；也不宜让每件日常器物都触发一场战斗。

## 十、失败、补救与旧器维修

### 10.1 失败需要有原因与阶段

【原创建议】不把小说中的风险直接复制成“未知概率碎装备”。

| 故障 | 前兆或可见症状 | 可补救方向 | 不可逆边界示例 |
|---|---|---|---|
| 选材不适配 | 功能模拟与材性冲突 | 改材料、隔离或减功能 | 已融合且无法分离 |
| 火力不足 | 材料未进入加工状态 | 换火源、延期或改工法 | 不强迫无意义持续烧炉 |
| 过火损灵 | 材纹消退、目标灵性降低 | 停火、保留剩余部分 | 关键天然结构已毁 |
| 去杂不充分 | 杂纹、灵力波动 | 返炼、局部处理 | 后续封装后返工成本上升 |
| 锻打伤坯 | 局部变薄、锤音改变 | 重新成形、加固 | 承力骨贯穿断裂 |
| 阵纹不通 | 灵路中断、局部不亮 | 抹纹重刻、填纹 | 刻纹越过天然关键结构 |
| 阵纹超载 | 全部能启动但持续失稳 | 减功能、换器胚 | 强行激活造成结构损伤 |
| 部件不匹配 | 单件合格、成套不同步 | 单件调校、换连接件 | 不应默认整套一起报废 |
| 客户难以操控 | 功能达标但耗灵过高 | 降耗、改法诀、换方案 | 未获同意不能直接交低配 |
| 灵性不稳定 | 器鸣紊乱、反应迟滞 | 温养、停止启灵、改普通器 | 完整器灵损毁须单独规则 |

【小说边界】《一念永恒》确有裂缝与废品表现，但本表的返工方法并非该作品原设。【S09】

### 10.2 推荐五种结果，而非二元成败

全部为原创结果模型：

- 达成全部委托要求。
- 核心功能合格、存在已披露瑕疵，客户确认后降价接受。
- 可返工，消耗工时与耗材。
- 改为其他合适产品，需另找客户或自用。
- 材料部分报废，剩余可回收，并承担约定责任。

不要把“做出一个偏差产品”全都叫失败。研究型游戏的乐趣在于理解偏差，而不是不断支付罚款。

### 10.3 旧器维修的四段流程

【设计归纳，受S15、S16启发；具体工法为原创】

**查症状 → 分结构与灵路故障 → 保留／替换／改用 → 同条件复测**

1. 查明客户什么时候出问题，是否遭遇过冲击或换了功法。
2. 分开判断器形裂损、阵纹断续、阵眼失效与认主联系异常。
3. 优先修坏的部分，不为补一道纹就把完整器物重熔。
4. 按同样测试方法复测，再确认是否存在隐患。

主角可以擅长“修复别人认为无用的器物”，但诊断仍需由玩家参与。自动见破烂就变神器，会使委托与工艺判断失去意义。

### 10.4 失败记录要成为知识

【原创建议】宗门手册记录“材料批次—工法—现象—判断—修正—复测结果”。

不要因为失败就直接奖励一份正确配方。失败先留下可信的观察结果，下一次对照试验才能建立结论。可复现的结论才进入弟子讲义，避免随机一次成功变成永久标准工艺。

## 十一、从弟子到宗师的修炼课程

本章为**原创课程设计**，不等于任何小说职业等级，也不绑定修仙境界。每一阶段包含新增判断、训练任务、晋级凭证与可交给弟子的工作。

| 阶段 | 主要学习 | 练习内容 | 晋级凭证 | 可委派的工作 |
|---|---|---|---|---|
| 识器入门 | 问用途、认材性、查器伤 | 鉴别两批外观相同的材料；修一件小器 | 正确诊断并解释处理方案 | 分选、清理、整理器簿 |
| 稳定制器 | 炼材、制坯、基础纹 | 制作一件可持续工作的灵田工具 | 不靠运气，重复满足同一验收 | 标准备料、常规制坯 |
| 功能定制 | 器图修改、客户适配 | 同一器图做节能款与轻便款 | 两款都有不同且可验证的优点 | 成熟款批量生产 |
| 复合炼器 | 多材料、关联纹式、成套匹配 | 制作一套阵旗或组合护具 | 单件及成套测试同时合格 | 分工制作标准部件 |
| 养器修复 | 温养、旧器历史、灵性异常 | 保留客户旧器身份完成改良 | 修复后稳定运行且未破坏约定 | 常规养器与售后记录 |
| 宗师创器 | 解决从未见过的约束组合 | 以受限材料完成新器图 | 新工艺可复现、可讲授、可扩展 | 将基础业务交给宗门体系 |

### 11.1 为什么宗师弟子开局仍要学

【原创建议】主角懂师傅的方法，但宗门现实条件不足：炉胆破损、地火不稳、资料残缺、弟子基础不齐、客户需求与旧器谱不同。

这种缺口可以让玩家从低阶订单开始，却不显得主角突然失忆。能力成长是“把高深传承变成现实可执行工艺”，而不是重复背诵师傅已经教过的一切。

### 11.2 日常修炼如何不挤压经营

- 新材料练习用小样，不抢客户完整原料。
- 示范课让弟子完成一部分工序，掌门指出偏差。
- 把失败器物放进练习台，对比正确和错误的灵路。
- 师傅手札先给观察问题，玩家试验后再获得解释。
- 晋级任务为真实订单或宗门工程，不只交纳大量灵石。

### 11.3 悟性、熟练度与经验

【原创建议】悟性可以表现为更容易获得可读线索或更快掌握某工法，不宜直接强制决定玩家能否理解答案。熟练度减少无意义操作，经验解锁已掌握工艺的稳定委派。

正确成长体验是：早期玩家亲手完成三件常规器物，后来教会弟子；掌门仍负责新材料、新客户与新器图，不再重复全部基础工序。

## 十二、炼器委托模板与完整案例

本章所有客户、器名、材料需求、验收目标与宗门收益均为**原创示例**。借鉴的是小说工艺问题，未移植原作人物与剧情。

### 12.1 委托条目的十个字段

客户身份、器物用途、核心要求、可妥协要求、客户供能条件、材料来源、允许修改范围、期限、验收方式、失败责任。

额外记一条“宗门收获”：不只收益，也可以是稳定供应、弟子练习、器谱线索或客户回访。不要让每个订单都同时给五种资源。

### 12.2 十二类委托候选

| 委托 | 核心难题 | 主要玩法 | 宗门关联 |
|---|---|---|---|
| 灵田的省力锄 | 能翻土，但不能榨干低阶修士灵力 | 器形＋低耗纹＋试作 | 形成稳定民生订单 |
| 采药人的轻身履 | 轻便与耐磨不能兼得 | 材料替代与局部加固 | 建立药材商关系 |
| 老客户的旧护身佩 | 保留家传身份修复断纹 | 诊断、局部修补、复测 | 维修口碑与回访 |
| 镖队的耐寒法盾 | 外层耐寒、内层灵路不能冻滞 | 分层材料、隔离纹 | 解锁环境型客户 |
| 矿队的引路铃 | 稳定辨路而不是攻击力 | 灵性与用途适配 | 获得特定矿料供应 |
| 弟子的初学法器 | 强度够用、操控负担低 | 新手适配、低耗定制 | 宗门内部培养 |
| 坊市的统一阵旗 | 单件合格还要成套一致 | 批量分工、关联校准 | 扩大生产组织能力 |
| 剑修的旧剑改良 | 改进重量，不能破坏习惯 | 配料、结构修改、客户试剑 | 高价值定制客户 |
| 地火阀组维修 | 几个部件异常影响整个工坊 | 部件诊断与连动测试 | 增加工艺产能 |
| 外宗的急件 | 赶工与稳定性取舍 | 排程、报价、风险披露 | 合作或声誉后果 |
| 残缺器图试制 | 不知道哪处工序缺失 | 小样实验、对照、记录 | 传承与原创器图 |
| 古器灵性恢复 | 不抹去历史而恢复联系 | 诊断、温养、慎重启灵 | 宗师传承线高潮 |

### 12.3 完整案例A：灵田锄——一件“有用”的第一单

**订单情境：**山下灵田种植户希望宗门修复旧锄或做一把省力新锄。使用者修为低、预算有限，要求连续作业，而非斩妖。

**借鉴出处：**《修真世界》震灵锄的物理器形与阵式结合。【S04】下列方案为原创。

1. 问器：确认主要工作是松土，不要求劈开坚石。
2. 鉴材：发现旧锄器骨尚可，原有灵纹断续；比较维修和新造两种报价。
3. 定谱：选择保留器骨、补一条低耗灵路；不强行增加攻击纹。
4. 炼材：只处理局部缺陷，准备少量回元墨与加固辅材。
5. 制坯：修正刃口与连接位置，避免为追求锋利削薄承力部位。
6. 布纹：修补通路，按低耗目标连接效果区。
7. 定型：封纹并稳定测试，不安排人格化启灵。
8. 试器：在相同土壤中比较旧器与修复器的连续作业效果；失败则先检查断纹，不重熔全锄。

**客户反馈：**“能连续做完这片田”比总评分提高更重要。**宗门收益：**第一笔可信维修收入、农具回访关系，以及可教给弟子的基础修补课程。

**课堂目的：**玩家第一次理解“不是材料越多、功能越多越好”，而是做合用的器物。

### 12.4 完整案例B：护身佩——高品质不等于适合客户

**订单情境：**一名采药修士需要护身佩，要求遭遇落石时能保护一次，同时保留足够灵力返程。

**借鉴问题：**材料与使用者适配来自定制思路；具体器物、承载预算与工法均为原创。【S17仅作流程启发】本单将炼材与制坯合为“雕刻加工”，不做全材熔炼；采用功能激活而非器灵启灵。最后的返工是验收后的分支，不是第八段工艺。

1. 问器：确认主要威胁是一次冲击，而不是长时间法术对轰。
2. 鉴材：选择天然纹路完整的清露玉，不把它熔为统一液料。
3. 定谱：从持续护罩与瞬时缓冲两种功能中选后者。
4. 雕刻加工：保留主纹形成佩坯，独立制作小型储灵阵眼；合并本单的炼材与制坯。
5. 布纹：先做通路，再连接护纹；是否增加回流功能受承载预算限制。
6. 定型与调校：封纹、稳定器形并激活功能，用客户可提供的灵力测试，避免以掌门充沛法力“假装适配成功”。
7. 验收交付：一次指定冲击后护佩仍稳定，剩余供能满足客户要求。

**返工分支：**若耗灵过高，缩减护罩范围或换低损通路；更换方案前确认客户认可。

**经营结果：**“高耗但华丽”和“低耗且够用”都可能制作成功，但只有后者符合这份订单。

### 12.5 完整案例C：四面阵旗——从单人匠人到宗门掌门

**订单情境：**坊市需要四面临时防护阵旗。旗与旗之间必须协调，而不是只收四件看起来相同的商品。

**借鉴出处：**《修真世界》关联剑胚各有不同符阵；组合器物在此改写为阵旗。【S06】本单先形成器图草案，再依材料鉴定结果修订；准备、单件制作和成套测试不是八段工序的一一编号。

1. 问器：确认布置范围、持续时间和负责催动的人数。
2. 鉴材：匹配批次，检查是否有某一件材料差异过大。
3. 定谱：设四件不同职责的阵旗，并根据材性确定成套关系；具体阵式均为原创。
4. 分工：弟子做杆体、底座与成熟加工，掌门监督关键纹路。
5. 单件制作：按炼材、制坯、布纹、封纹定型顺序完成每件；每件先达到自己的职责目标，不以外观一致代替功能合格。
6. 关联调校：用试灵台观察协同启动、负载分配与收束。
7. 故障处理：第三面旗失步，定位是连接件问题，只返修该件，不把四面一起报废。
8. 交付：现场按客户供能条件布置；整理可复现工艺为弟子讲义。

**宗门收益：**获得一笔工程委托、建立成套校准能力，并让掌门第一次从“亲手做四件”转向“组织别人共同做成一套”。

### 12.6 两个进阶事件，不必立即实现

- **残图补谱：**师傅手札指出一处反常材纹，玩家通过小样对照判断该保留还是去除。成功奖励是明确工艺知识，而不是凭空解锁所有高阶器物。
- **古器回访：**客户带回宗门以前修过的器物，实际使用产生新的灵性反应。先确认温养与使用情况，再判断要不要启灵，不因出现异象就直接升级为神器。

## 十三、炼器如何带动宗门发展

### 13.1 三条互相咬合的成长线

【原创建议】

- **掌门成长：**识别更难的工艺问题、读懂传承、创造可教的方法。
- **生产成长：**弟子、工坊、材料来源使已掌握工艺变得稳定可复制。
- **宗门成长：**口碑、客户和合作关系带来新约束与新订单。

核心循环是：**完成委托 → 得到收入与可信经验 → 修复设施／传授弟子 → 承接更复杂委托。**

宗门变强不只因为建筑等级高，而是能承诺并稳定交付以前做不到的东西。

### 13.2 没落宗门的资源与资产

【原创建议】初版优先保留四种可理解对象：

| 对象 | 用途 | 典型获得方式 |
|---|---|---|
| 灵石 | 购买材料、维护设施与支付事务开支 | 交付合格订单 |
| 灵材与半成品 | 真实生产投入 | 采购、客户来料、回收 |
| 器谱与讲义 | 可执行知识与教学依据 | 研究、传承、复盘 |
| 声誉与客户关系 | 新订单、可信合作与回访 | 稳定交付、处理返修 |

不要把“宗门底蕴”“道韵”“器道点数”“研究点”“师承点”全做成不同货币。先用器谱、设施、弟子能力等具体资产表现底蕴。

### 13.3 宗门空间如何随着工艺变化

- 第一阶段：鉴材桌、旧炉、砧台、委托簿，能做小器与基础维修。
- 第二阶段：修复地火室与刻纹台，能稳定制作常规器物。
- 第三阶段：增添试灵台、弟子工位与藏谱阁，能做定制、批量与成套订单。
- 第四阶段：建立养器位与复杂试制空间，能承接成长器、灵性恢复与宗门工程。

每次扩建都应有新工作可做，不能只有视觉面积增加。具体建设顺序依之后选择的核心玩法调整。

### 13.4 弟子能力与派单

【原创建议】先让弟子按工序形成特长，例如鉴材、稳火、制坯、刻纹、试器。掌门可选择：亲自指导、让师兄示范、分配低风险任务或暂停接难单。

常规工序经过掌门验证且弟子学会后，才允许稳定委派。不会的步骤不能靠“弟子等级更高”自动凭空学会。

产量与培养之间应有轻量取舍：今天少接一单传授刻纹，之后能释放更多掌门时间。教学应产生可观察技能变化，不做纯等待任务。

### 13.5 供应、报价与赔偿

【设计归纳】《修真世界》的高品材料赔偿风险说明接单能力不等于必须接单。【S05】

【原创建议】

- 客户来料：材料损耗与返工范围提前写明。
- 宗门供料：报价包含原料、工时、耗材、试制与风险。
- 稀有材料：先做小样，必要时申请额外加工余量。
- 急件：提高费用，同时展示调度冲突，不偷偷提高未知失败率。
- 返修：区分工艺缺陷、客户误用与新环境需求，按约定处理。

不能把前作中的强制上贡结构未经判断就换名为宗门税贡。本项目的主要压力应来自经营承诺、订单选择与传承成长，而非必须给压迫者交物。

### 13.6 神秘师傅与宗门复兴的连接方式

以下是原创叙事候选，不是用户已经确认的具体剧情：

- 初期，手札帮助玩家识别某种常见器伤，证明师承确有价值。
- 中期，宗门旧谱与师傅手札对同一种材料处理给出不同解释；玩家通过试制发现过去工艺的适用条件。
- 后期，客户古器或外宗工程提出手札未给答案的问题，掌门必须自己补谱。

主角成为掌门的成长高点应是“把师傅的个人绝艺变成宗门能传下去的体系”，而不只是终于知道师傅真实身份。

## 十四、下一步玩法设计的取舍建议

### 14.1 三种方向，不提前锁死一种

| 方向 | 核心乐趣 | 主要借鉴 | 适合的订单 | 实现风险 |
|---|---|---|---|---|
| 亲手锻炼型 | 火候、锤击、器形变化与成器反馈 | 《龙王传说》＋《凡人》工艺细节 | 金属器物与结构维修 | 所有器类最后都变成敲剑 |
| 阵纹解题型 | 材料、器图、灵路与功能取舍 | 《修真世界》＋定制流程 | 玉佩、灵盘、成套器 | 退化为固定答案拼图 |
| 委托经营型 | 诊断、报价、派单、传艺与扩建 | 工坊分工＋半成品加工 | 维修、批量、急件 | 界面繁杂，炼器沦为计时器 |

**推荐组合：**亲手操作承担关键短时反馈，阵纹与材料承担主要决策，委托经营提供目标与成长。不是三套同等复杂的大系统并行，而是围绕一件器物的同一个问题组合。

### 14.2 最小验证范围

【原创建议，不是最终开发排期】先用一个小工坊验证循环：

- 两类器物：金属农具与护身佩。
- 三种关键操作：鉴材、锻打／控火、基础刻纹。
- 三类业务：维修、制造、客户定制。
- 一名弟子：学会一个成熟工序后替掌门承担它。
- 一个建设目标：修好工坊中的关键设施，从而解锁真实新订单。
- 一条传承线索：解释一个可通过实验验证的工艺现象。

先不同时制作完整器灵养成、空间法宝、飞舟、傀儡与器劫。扩展候选可以留在器谱中，但不影响基础循环是否成立。

### 14.3 值得优先验证的四个问题

1. 玩家是否知道自己为什么选这份材料、这条阵纹或这个火候？
2. 器物成败能否回指玩家的判断，而不是只有随机弹窗？
3. 委托是否真的要求不同用途，而不只是不同等级？
4. 教会弟子后，掌门是否获得新工作，而不是继续重复全部旧操作？

若这四个问题成立，东方玄幻背景才真正改变了玩法，而非单纯把铁矿换成玄铁、把炉子换成丹炉。

### 14.4 后续规格需要另行决定

- 视角：第一人称工坊、第三人称掌门或俯视经营。
- 操作强度：精准动作、轻操作判断或主要选择式。
- 时间结构：日／旬经营回合与短时工艺操作的配比。
- 器物层级：先按功能定义，再统一命名。
- 成长边界：个人修为、职业认可与宗门等级各自作用。
- 风险：可返工范围、最低收益保障、赔偿与自主停止。
- 幻想尺度：是否采用人格化器灵、本命器与器劫。

本手册不替这些尚未明确的选择做最终决定，可在下一轮根据想要的手感和制作规模收敛成具体炼器系统。
